# 网页重构：苹果设计原则与信息对齐

用户要求直接完整重构。保持局域网只读、无需账号/证书/云服务，不恢复手机推送。现有 `outputs/` 下的用户文件不属于本次修改。

## 设计与信息清单
- 手机：大标题、在线/离线摘要、搜索和分段筛选、类型图标列表；详情独立导航，浏览器返回与页面返回一致。宽屏：列表/详情分栏，保持选择和滚动位置。
- 详情：设备名称/类型/原始名称、自定义图标映射、在线状态/当前在线时长、连接频段/IP/MAC、下载/上传实时速度与累计量、合计与记录日期范围、1/5/10 分钟曲线及触摸/键盘数据游标、首次发现/最后在线、Windows 提醒状态、全部历史分页与每次持续时间。
- 网络：连接状态、IPv4 全部 5 项、IPv6 全部 6 项、Mesh 名称/硬件/IP/连接方式/设备数/主节点标记。
- 关于与监控信息：刷新周期、桌面偏好、Windows 提醒/免打扰、版本及数据新鲜度。不暴露管理员密码。
- 动效：只在真实导航、筛选和用户操作时触发；中途可反向，不锁输入。数据轮询更新已有节点，不重建焦点/滚动容器。不伪造缺失曲线，不循环装饰动画。
- 可访问性：系统字体、至少 44 CSS px 触控目标（网页实现映射，非声称 CSS px 等于所有设备的物理 pt）、安全区、浅深主题、减少动态效果/透明度、高对比、键盘及语义标签。

## 图标
实测旧 PNG 为 512×512，其中 123836 / 262144 像素非不透明。以可编辑 SourceIcon.svg 为识别元素重新制作独立网页图标，完整不透明方形背景，由系统裁切圆角；1024 母版，180/167/152 Apple Touch Icon，192/512 manifest 图标。图形留白为设计选择，不编造苹果规定统一百分比。使用新文件名避免旧 URL 缓存；已有 iOS 主屏幕书签可能仍需删除后重新添加。

官方依据：
- https://developer.apple.com/design/human-interface-guidelines/app-icons
- https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/ConfiguringWebApplications/ConfiguringWebApplications.html
