# dev.208 统一侧栏

导航并入设备栏上方，不再保留独立固定导航栏。展开布局依次为软件标识／收起按钮、设备／路由器／设置横向入口、在线离线选择及设备列表、连接状态与更新时间。软件标识只在统一侧栏中展示，避免标题区重复。

依据用户指定的 ChatGPT 网页实测及其可见 DOM/CSS：折叠栏保留窄形态，点击空白处可展开；软件标识与展开图标共用同一位置；悬停规则含 150ms 延迟，键盘焦点不等待。没有读取或声称获得未公开的产品源码。

本实现收起后为 56 宽窄栏：整栏使用一个展开按钮，图标、空白和底部区域都由它接收点击，首次点击只展开、不误触导航。普通状态显示软件图标，悬停延迟后切换为侧栏图标，移出恢复；键盘聚焦直接提示展开。悬停离开或反向操作会取消过期回调。

保留 260ms 宽度过渡、内容淡入淡出、快速反向及恢复原宽度。设备选择和列表实例保持不变，导航行增加柔和的悬停反馈；系统关闭动画时收放直接完成。

验证：Release 构建；展开／收起及反向；整栏空白处命中和 UI Automation 展开；软件图标悬停延迟与恢复；导航入口和选中设备保留；最小窗口及明暗主题；复制地址、图标等距与网速基线回归。
