## 图标源与转换修复

使用 [Lucide](https://github.com/lucide-icons/lucide) 提交 `2b9bbdf444512dcf955a6a9fee99937176cf7535`，源 SVG、来源和许可证存放于 `ThirdParty/lucide`。`scripts/build-device-icons.py` 同时生成 WPF Geometry 和网页 SVG 映射；许可证随发布包分发。

迭代中曾将多个独立 SVG path 拼成单条 WPF path，导致后续相对 moveto 继承前一条路径的终点，“其他设备”图标发生越界。现改为每条 SVG path 独立解析，再放入 GeometryGroup；圆角矩形保留 SVG 圆弧。不是依靠裁剪隐藏越界。

16 类图标的 WPF 描边边界和浏览器 getBBox 均在 24×24 画布内。包括摄像头的实际图标总览保存在 `.tools/ui-dev230/device-icon-atlas.png`。

## 动画复核

| 之前 | 现在 | 原因 |
|---|---|---|
| 指示器 220ms、列表 1040ms，详情先退场 260ms | 三者同时启动、480ms 结束 | 消除速度和内容更新时机的不一致 |
| 列表 Quintic EaseOut 长尾 | Cubic EaseOut | 保留用户要求的横向空间过渡，缩短拖尾 |
| 新设备沿用旧设备滚动位置 | 设备身份改变时回顶 | 使新内容从标题开始呈现 |
| 设备行无按压缩放 | 100ms 按压、240ms 释放，反向时接续当前值 | 与现有表单交互协调，避免时钟残留 |

480ms 用于整个内容面的位移而非普通按钮反馈。快速反向、关闭到托盘、禁用系统动画的即时状态路径均保留。复核结论：本轮要求对应的时序与反馈检查通过。
