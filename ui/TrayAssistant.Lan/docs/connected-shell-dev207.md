# dev.207 连续外壳与带文字的导航

按用户提供的 Codex 与 Breeze 截图调整结构：标题区和固定导航共享外层背景，导航不再单独绘制圆角框；设备栏与详情区共用一个圆角内容面板，中间保留分隔线及可拖动的宽度调整区域。

- 固定导航列从 64 增至 80 个逻辑像素；导航按钮使用较大的图标，并在下方常驻显示设备、展开／收起、路由器、设置名称。
- 左上标题区显示 20 大小的软件图标和完整软件名称；保留 Windows 窗口拖动及最小化、最大化、关闭控件。
- 当前导航的选中底色集中于图标区，标签仍保持可见。
- 保留设备栏独立收放动画、快速反向、宽度恢复及固定导航不动的行为；按新的导航宽度重新计算窄窗口边界。

验证：Release 0 警告／0 错误；软件名称和图标可见性、导航文字、共同内容容器结构；设备栏动画及反向；窄窗口、明暗主题、图标等距和网速基线；设置和反向筛选回归。真实安装截图与旧版备份不纳入提交。
