# dev.231 自绘图标与反馈修正

- 按旧网页圆角线性图标的风格重绘全部 16 类设备，统一为 24×24、1.65 描边，包括双天线路由器、仪表式空气检测仪、无线传感器与带底座的摄像头。桌面、下拉列表、底部路由器按钮和网页共用 `Assets/DeviceIcons` 源文件及生成器。
- 移除当前代码中的 Lucide 设备图标源与发布依赖。未知类型仍回落为“其他设备”，不是空白或越界图形。
- 胶囊按压使用独立弱暗色遮罩：浅色 alpha 从 50/255 降到 20/255，深色从 80/255 降到 32/255。圆按钮的按压强度保持原样。
- 胶囊和圆按钮悬停提亮加强：浅色白色遮罩 alpha 从 96/255 增至 224/255，深色从 36/255 增至 80/255；边缘也随悬停提亮。
- 修正上一轮对详情动画时长的额外调整：详情恢复原先约 1040ms 总时长。设备列表与筛选保留当前 480ms，但新详情立即更新并同时开始动画，不重新引入等待旧内容退出的延迟。
- 字体、设备信息、滚动回顶、免打扰状态、弹层宽度与对齐沿用已确认实现。
