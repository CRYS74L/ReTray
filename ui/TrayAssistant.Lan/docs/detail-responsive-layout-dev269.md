# 竖屏连接信息与流量标题布局（dev.269）

连接信息原有 Justify 布局在每行分别按内容宽度贴两端排列，因此换成两列后，状态/IP、类型/MAC 的列中心不一致。仅此区域启用 EqualCellsWhenWrapped：四列维持原来的分配，两列使用统一列宽与中心；完整文字放不下等宽列时才进一步变为单列。

流量统计标题原来以两列各至少 220 DIP 判断换行，与标题和 228 DIP 滑块的实际尺寸不符。标题区域改用自然尺寸判断，放得下就保持标题左侧、滑块右侧。字号、滑块宽高、标题左距、材质及其他自适应区域的模式不变。

回归先复现旧代码错误：440 DIP 窗口中，流量标题可用 369.6 DIP、所需约 325.2 DIP，仍被换行；连接信息上下两行列中心也不一致。

修复后检查浅/深色 380–1180 DIP，包含宽窄往返。每次先完成响应式模式切换再显示详情，明确断言详情可见；验证两列中心、文字完整性、标题与滑块同排、空间真正不足时的换行、滑块边界与原有 228×36/13 号字体。保留独立离屏渲染截图，不操作用户鼠标或真实设备记录。

Release 构建、详情布局、窗口自适应及缩放缓存检查通过。
