# 历史时长胶囊与展开按钮（dev.268）

历史展开/收起按钮沿用圆形按钮的尺寸、交互和箭头动画，仅描边改为与记录卡片相同的 TimelineItemBorderBrush、1 DIP。删除悬停说明，保留读屏操作名称。

旧 CompactGrid 在宽度低于 440 DIP 时无条件把时长胶囊移到日期下方。基线回归在窗口宽 500 DIP 时复现：行可用宽度 366.4 DIP，完整内容只需约 308.4 DIP，仍错误换行。

SessionHistoryRow 按日期区与时长胶囊的自然尺寸判断是否放得下，保留 24 DIP 标记区、12 DIP 横向间隔和两物理像素余量。空间足够就保持胶囊在右侧；确实不足才移到日期下方。字体、日期间隙、胶囊描边及内边距保持原样。

不同记录在窄屏可能具有不同行高，历史虚拟化面板因此缓存各行高度与累计偏移，仍只创建视口附近记录。展开高度按实际累计高度及当前行的动画进度计算，避免平均行高导致裁切。保留原有展开/收起时长和可反向的动画。

验证使用虚构设备及独立离屏窗口，不操作实际鼠标、监控或用户记录：

- 基线布局同排断言失败，修复后的浅/深色 380、500、600、1180 DIP 检查通过，500 DIP 渲染截图中时长胶囊保持同排。
- 46 条混合记录展开到 18、33、全部，再收起；深滚动、末条可达性、缩放、行间重叠与最后一行裁切检查通过。
- 原历史展开动画、日期间隙、标题及按钮上下间距回归通过；窗口自适应检查通过。
- 100 条历史视口检查通过：完整记录保留、中部与末尾可达、切到短历史不留长尾。探针明确先展开当前设备，并按行累计偏移定位中部记录，避免把默认收起状态或整页滚动中点当作第 50 条历史的位置。
