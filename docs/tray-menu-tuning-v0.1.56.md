# 自身托盘菜单的原生调节候选

根据用户从 HTML 调节台导出的 v1 参数，将自身托盘菜单改为独立模板。其他下拉框保留原有尺寸。

| 项目 | DIP 值 |
| --- | --- |
| 宽度 | 随最长文字自动计算 |
| 面板圆角 / 描边 | 15.75 / 1.5 |
| 面板左、上、右、下内边距 | 1 / 1 / 1 / 1 |
| 行高 / 每项上下外边距 | 28 / 0 |
| 高亮圆角 | 40，在 28 行高下按胶囊形显示 |
| 字号 / 字重 | Noto Sans SC 13.5 / Regular |
| 文字左右内边距 | 10 / 10，保留原始字形边缘补偿 |
| 文字垂直偏移 | 0 |
| 阴影模糊 / 距离 / 不透明度 | 22 / 6 / 7% |

逐项微调和额外项间距均为 0。深浅色配色、悬停过渡时间、语言标签、点击锚点和菜单关闭行为保持原参数。

原生描边使用标准 WPF Border，保留 1.5 DIP 厚度，避免共用 RoundedCardBorder 将其取整。简体中文目标面板尺寸约 79.0405 × 89 DIP，最长文字可见左、右留白均为 12.5 DIP。

这是等待用户原生效果确认的本地候选；数值版本用于 EXE 标识，Git 标签使用开发后缀，不推送 GitHub。

验证使用与便携版一致的 .NET 8 运行时。菜单生命周期检查通过：可见文字留白与目标尺寸、垂直居中、125% DPI 点击锚点、界面内菜单驻留、Esc / 外部点击关闭以及隐藏主窗口后的菜单驻留。测试夹具通过输入队列取得前台，并按真实入口将隐藏窗口菜单请求排入 Dispatcher，避免直接同步调用与前一菜单焦点清理相冲突。

便携程序已在原目录就地更新并启动，程序和 Data 已在本地忽略目录备份。运行时就绪、Shell 连接正常，125% 系统缩放下实际菜单窗口为 129 × 146 像素（包含原有阴影留白）；该窗口截图只保留在本地，外观仍待用户确认。
