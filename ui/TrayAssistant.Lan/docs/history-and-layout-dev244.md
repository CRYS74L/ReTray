# 历史展示与布局调整 dev.244

- 历史外显数量为最近三天相关会话数与最近三段会话数的较大值。总数不超过三段时全部显示，不出现折叠按钮。展开与收起按钮位于记录下方；保留可反向操作的非线性高度动画。
- 两个端点的日期与时间独立布局，固定间距 10 DIP，不再被另一行的完整日期撑宽。
- Mesh 标题与地址合并为连续内容块，宽屏数量块位于右侧，窄屏数量徽章保留在元信息下方。标题到地址的实际间距为 8 DIP；重启图标与文案的实际间距为 20 DIP。
- 设置页四个分组标题复用设备详情的 16 DIP 半粗体与标题颜色，保留左侧对齐。
- 深色外层面板与内容卡片的透明度分别小幅提高，保持原有中性色值、描边与小控件层级。浅色主题不变。

## 验证

历史回归覆盖零至五段旧会话的实际显示高度、最近日期分类、按钮位置、混合日期长度、刷新与切换设备、动画中间高度和反向操作。Mesh 回归检查浅深主题及 1180 / 430 / 380 DIP 宽度下的跨行布局与标题到地址间距。

六项专项通过：`--history-disclosure-regression`、`--sidebar-topology-regression`、`--status-appearance-regression`、`--popup-alignment-regression`、`--visual-polish-regression`、`--responsive-navigation-regression`。其中包括原有描边、滚动渐隐、呼吸动画、菜单对齐和响应式导航。原生窗口截图确认 Acrylic 生效并复核深色设置页，构建零警告、零错误。

本次使用受影响行为的专项回归；未重跑含旧断言的历史全量控件套件。
