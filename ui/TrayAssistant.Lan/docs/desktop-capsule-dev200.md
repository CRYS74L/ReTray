# dev.200：分段文字层级与胶囊比例

修复分段文字始终呈现主文字色的问题：全局 TextBlock 样式具有显式 Foreground，覆盖了 ListBoxItem 的继承颜色。分段控件现在为内部 TextBlock 提供局部样式，直接绑定选项的最终前景色、字重和字号。浅色未选中项为中性灰，深色使用浅灰；选中项使用主题主文字色。

本轮同时调整形状与内容布局：

- 设备条目使用胶囊外形，64 最小高度、14/10 内容边距、40 圆形图标；设备名保持 14 字号，连接与速度使用 12 字号。过长名称省略并可悬停查看完整名称。
- 地址、密码、时间和下拉框统一 40 最小高度；输入框仅保留一次内边距，修复原模板重复使用 Padding 造成高度膨胀的问题。
- 局域网地址与复制按钮等高，普通操作按钮按文字高度重新配置留白；顶部按钮调整为 36 高度。
- 胶囊圆角仍根据实际高度计算，保留分段窄边距、关闭开关灰度，以及上一版已移除的焦点蓝框。

参考了用户明确指定的 ChatGPT 网页顶部“聊天／工作”控件的文字层级。这里的尺寸是针对 WPF 桌面、当前字体和窗口空间的实现选择，不声称是 Apple 官方规定的固定像素值。

验证包括 Release 构建、分段文字最终颜色检查、输入框和按钮实际尺寸检查、开关状态位置、明暗主题与 980×650 / 1180×760 布局、多设备列表渲染、设置快捷键回归和快速反向筛选回归。离屏渲染按系统 DPI 导出，并快照动画的当前变换，避免导出图误用缓存的动画初始位置。测试数据和截图均为本地辅助文件，不提交真实设备数据。
