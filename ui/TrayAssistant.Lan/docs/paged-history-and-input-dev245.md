# 历史分段展开与输入定位修复 dev.245

- 默认显示最近三条上下线区间。每次点击记录下方的展开按钮最多追加二十条，最后一页只追加剩余记录。全部展开后隐藏展开按钮，独立收起按钮可回到三条；保留动画中途反向操作、刷新保留页数、切换设备复位和原有虚拟化。
- 文本输入框的 `PART_ContentHost` 原来按文字高度居中，宿主只覆盖约 28 DIP，点击上下留白时不能定位字符。现在宿主覆盖完整的 44 DIP 输入区域，文字仍居中；文本与密码输入宿主不再使用页面通用滚动样式。
- 原生枚举与 UI Automation 确认桌面左上角的 27×17 白色椭圆属于助手进程的空 `ToolTip`。提示框打开时更新内容绑定并立即关闭空内容提示；正常说明与累计流量的日期提示保留。
- 数字与中文时间单位、中文日期采用 U+2009 细空格。历史时长胶囊略微提亮。
- Mesh 数量块标签改为“连接设备”；互联网状态移至路由器标题旁；路由器操作标题统一为同页分组标题样式和左对齐。
- 设备提醒文案为“当设备上下线时，推送 Windows 通知”；IPv6 提醒合并为“当 IPv6 连接类型不是 Native 时，推送 Windows 通知”。中英文交界保留细空格。

## 验证范围

- 历史回归覆盖零至五条、47 条逐页显示 `3 → 23 → 43 → 47`、刷新保留页数、收起、反向动画及日期间距。
- 输入回归使用隔离的 WPF 输入设备，验证未聚焦输入框的留白和文字区域单击、拖选、刷新保留选择范围、字符替换，以及空／正常／绑定日期提示的生命周期。不会移动用户的物理鼠标；结束时释放测试窗口的鼠标捕获。
- 复查浅深色、描边、侧栏渐隐、菜单对齐、Mesh 和响应式导航。使用原生窗口截图及部署文件 SHA256 校验；历史全量旧控件套件未重跑。
