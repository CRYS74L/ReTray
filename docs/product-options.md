# 当前功能

顶部按顺序提供托盘图标、系统图标、设置三页，内容与滑块之间相隔 6 DIP。自有界面文字使用内嵌 Noto Sans SC，符号使用内嵌 Segoe Fluent Icons。

## 托盘图标

显示所有当前注册的应用图标。开关负责显示或隐藏，Windows 管理任务栏、折叠区位置及实际托盘顺序。拖放只改变助手列表顺序，透明整行预览随鼠标移动。点击图标执行原应用的左键、右键或双击交互。

所有应用的列表图标使用独立显示帧：原生空白或全透明帧保留本次注册最后的有效画面，首次读取空白时可使用已有原图，自定义图标应用时预存替代图像。原生实时帧继续反映闪烁，任务栏行为和消息菜单保持不变。注册移除后释放显示缓存，处理逻辑不按程序名称特判。

列表图像在原像素外保留透明采样边界，并以原图区域对齐屏幕像素，缩放时不裁去四边。三点按钮分主题提亮并保留描边。图标设置使用窗口内浮层，原图与替代图使用统一预览画布，由 36 DIP 高度的滑块切换原图／替代图模式；替代图画布可选择文件，切回原图保留选择，自定义悬停提示内容输入框同为 36 DIP 高度。背景与顶部滑块同步模糊，输入框两侧完整保留聚焦光晕。修改自动保存；叉号、Esc、外部空白关闭浮层。

## 系统图标和设置

采用 34 DIP 紧凑单行、细分隔线和小开关。系统图标单目标操作成功后才保存，失败保留原偏好；当前不存在但已有隐藏偏好的目标允许解除隐藏，不创建旧版替代图标。

系统页不提供通知和快速设置选项。网络、音量、电源从当前 Windows 控件读取字形，在助手窗口内按原点叠加组合图形，完整显示喇叭主体及声波。输入法读取 Windows 输入法组件的图标；时钟、隐私指示器采用 Windows 自带的 Clock 和麦克风符号；开始读取 System32 的 Windows 窗户图像。没有在 Explorer 中调用 RenderTargetBitmap 或异步图像渲染。

开始通过 StartButton 标识区分，隐藏只改变透明度及鼠标命中，保留 Windows 的布局和开始菜单定位对象；任务视图不在其控制范围内。隐私指示器的开关始终反映已保存的允许显示偏好，无论当前有没有指示器均可改变，不跟随麦克风使用状态跳动。

输入法行在显示／隐藏开关左侧提供三点按钮，打开与托盘图标相同的编辑浮层。每个已启用的 TSF 输入法占一行，未激活输入法也直接展示注册标志；每行独立选择原图或替代图，切回原图保留已选文件。仅替换标志，输入状态图标不在编辑范围内。

输入法选择控件与中英语言指示分别显示、分别控制。旧版合并的隐藏偏好在首次读取时拆到两项，之后独立保存。

隐藏偏好提前送入系统控件所在的 XAML 线程，在新控件布局结束、画面呈现之前生效，并同步监听已存在控件的可见性变化。读取页面不再负责事后重复隐藏新对象。

设置仅保留开机启动、主题、语言，底部显示实际软件版本。下拉项悬停胶囊与 132×28 DIP 选框宽高一致，外围菜单采用 6 DIP 内边距和 20 DIP 圆角。始终保留 14 DIP 滚动条列，显隐不改变布局。

自启动使用当前用户专属的无延迟登录计划任务；安装版通过固定位置启动器激活同一安装身份的后台，并适应版本更新。仅操作助手自己的任务，既有其它自启动项目不改。

配置在本机自动保存。软件不提供导入或导出配置功能；旧配置与已保存的个人图标保留。取消的高级行为不会通过旧配置重新激活。

## 窗口和菜单

关闭主窗口隐藏界面，后台和图标规则继续运行。助手托盘图标单击唤起界面；简洁菜单提供打开、重新启动、退出，以 12 DIP 字体、27 DIP 行高和 8 DIP 圆角显示。主窗口标题图标及文字右键也能打开该菜单。退出停止后台并撤销当前运行的策略。

## 字体

完整嵌入本机 Noto Sans SC 100–900 可变字体；当前 .NET 8 WPF 使用同源九档真实字重兼容资源，无合成粗体，未声明支持任意连续轴值。自有文字统一 Ideal / Auto / Auto；下拉文字与背景阴影分层。原生助手菜单使用同源私有进程字体，Windows 文件选择框与第三方托盘菜单由系统或第三方软件绘制。
