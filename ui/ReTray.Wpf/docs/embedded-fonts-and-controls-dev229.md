# dev.229 字体统一、内嵌与控件修复

## 字体与视觉基线

- 桌面主窗口、表单、下拉列表、工具提示、托盘菜单与流量图表统一引用 AppTextFont：用户修改后的 Microsoft YaHei UI（实际苹方字形）。三个 TTC 原样打包，SHA-256 与本机对应字体完全一致。符号图标使用原样内嵌的 SegoeIcons.ttf。
- 输入框、密码框、下拉框由另一套 PingFang SC / SemiBold 改为上述统一字体 / Normal；软件名称由 SemiBold 改为 Medium。实测这套字体的 Medium 解析到常规字体文件，SemiBold 解析到粗体文件。其他文字的字号、字重、颜色和渲染参数不变。
- 使用同一机器、同一界面状态的系统字体与内嵌字体做像素比较。20 个场景覆盖设备页、设置页、浅深主题、1180/980 宽度；按 100%、125%、150%、200% 渲染比例采样。内嵌切换的 4,608 个样本完全一致；加入明确要求的底部图标位置调整后，排除这两个图标的 160 个样本，其余 4,448 个样本仍完全一致。
- 对比检查包含文字内容、字号、字重、布局尺寸、像素 SHA-256，以及实际 GlyphTypeface 的 pack URI；不是仅比较 FontFamily 名称。输入与下拉文字、软件名称是明确要求改变的对象，未计入“不变”样本。上述结论针对已采样文字与当前本机环境，不将其扩大为所有显卡/系统上的像素保证。
- 网页也统一使用此字体。Light / Regular / Bold 的完整 WOFF2 编译进程序资源，由 `/fonts/app-text-*.woff2` 提供。CSS 正文、控件与 SVG 图表文字全部引用 App Text，不使用 local()、系统字体列表或远程字体服务。网页外观变化已获用户明确授权。

## 原对话要求复核与补充修复

| 要求 | 处理及证据 |
|---|---|
| 底部圆形按钮反馈、细描边 | 保留 0.75 DIP 描边，浅深主题悬停/点按/释放回归通过 |
| 设备胶囊统一灰色描边 | 普通、悬停、选中状态均使用共用灰色资源，逐项复核 |
| 软件标识比例与字重 | 保留 30 DIP 图标、18 DIP 名称；名称减轻字重 |
| 侧栏展开/收起图标大小与粗细 | 保留 24 DIP 宽度，将放大后约 1.96 DIP 的轮廓减至约 1.35 DIP；按实际宽高比设置高度，使可见轮廓居中；圆形悬停态保持 |
| 按钮图标居中 | 修复字体行框与字形边界不对称造成的约 0.6 DIP 偏移；按按钮中心与实际字形边界校正，测得两轴误差均小于 0.1 DIP |
| 左右分离卡片，红绿灯置于外部 | 保留两张 24 DIP 圆角卡片与顶部独立控制区域，布局回归通过 |
| 下拉框与输入框文字起点 | 共用 13 DIP 外层留白，下拉内容补上 WPF TextBoxView 的 2 DIP 内层留白；本机 125% 下两者起点均为 14.4 DIP |
| 下拉图标不丢失 | 全设备类型逐项切换，符号字体保持内嵌图标字体，不被普通文字同步覆盖 |
| 下拉点按颜色、收缩动画 | 胶囊底色不因点按变灰，保留收缩、弹层开合与反向动画，选中项不使用粉色 |
| 输入框聚焦高光 | 描边与光环使用 AccentColor / AccentBrush，随浅深主题切换 |
| 开关颜色与透明度 | 开启使用主题蓝；关闭轨道浅色 alpha=179/255、深色 alpha=153/255，保留滑块运动与依赖字段联动 |
| 红绿灯与历史颜色 | 保留更饱和的符号颜色，历史圆点沿用对应红绿灯表面红/绿色；原生命中和四档缩放像素检查通过 |
| 弹层圆角与详情标题 | 弹层继续共用 24 DIP 卡片圆角；详情标题保留 16 DIP、SemiBold 和较淡颜色 |

## 验证

- Release 构建：零警告、零错误。
- `--apple-controls-regression`：字体资源、按钮字形中心、文字起点、下拉图标、动画、五个开关、设置联动、卡片及浅深主题布局通过。
- `--web-access-regression`：新增字体路由检查先复现旧实现不可用，修复后全部通过；字体响应为 WOFF2 与正确 Content-Type，服务器确实从程序集提供字体。
- `--chart-regression`、`--close-to-tray-transition-regression`：通过。
- 通用无参数自检和 `--startup-smoke` 退出码为 0，但无完整检查输出，不将其列为全套测试通过证据。
- 浏览器验证：Browser 插件未提供，使用已有 Playwright；1280×900 与 390×844 页面、设备选择交互、无横向溢出、无控制台错误通过。三个字重加载完成，浏览器报告 Microsoft YaHei UI 的 `isCustomFont=true`。截图与记录位于 `.tools/ui-dev229/web-*.png` 和 `web-font-proof.json`。
- 桌面像素对比位于 `.tools/font-proof`，仅本机辅助证据，不提交采样图片或用户运行数据。`LAN_FONT_PROOF=compare` 需要先准备同场景的系统字体基线；普通回归不依赖本地基线文件。

Windows 自己绘制的通知中心、系统对话框等界面由 Windows 决定字体，不属于应用自绘文字。
