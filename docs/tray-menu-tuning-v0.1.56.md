# v0.1.56 自身托盘菜单定稿

根据用户从 HTML 调节台导出的 v1 参数，将自身托盘菜单改为独立模板。其他下拉框保留原有尺寸。

| 项目 | DIP 值 |
| --- | --- |
| 宽度 | 随最长文字自动计算 |
| 面板圆角 / 描边 | 19 / 1.5 |
| 面板左、上、右、下内边距 | 3 / 3 / 3 / 3 |
| 行高 / 每项上下外边距 | 29 / 0 |
| 高亮圆角 | 40，在 29 行高下按胶囊形显示 |
| 字号 / 字重 | Noto Sans SC 12.75 / Regular |
| 文字左右内边距 | 11 / 11，保留原始字形边缘补偿 |
| 文字垂直偏移 | 0 |
| 阴影模糊 / 距离 / 不透明度 | 22 / 6 / 7% |

逐项微调和额外项间距均为 0。深浅色配色、悬停过渡时间、语言标签、点击锚点和菜单关闭行为保持原参数。

原生描边使用标准 WPF Border，保留 1.5 DIP 厚度，避免共用 RoundedCardBorder 将其取整。简体中文目标面板尺寸约 82.03825 × 96 DIP，最长文字可见左、右留白均为 15.5 DIP。

用户已确认当前参数，正式版本为 `0.1.56`，设置页显示 `v0.1.56`。`VERSION` 与 Git 版本标签保持一致；设置页读取程序集 InformationalVersion，开发版本会完整保留预发布和构建元数据。Windows AssemblyVersion / FileVersion 使用数值 `0.1.56.0`，原生运行时与发行文件名使用完整版本。后续修改开发号只需更新 `VERSION`。

验证使用与便携版一致的 .NET 8 运行时。调参候选可用 `--appearance-only` 单独检查设置页完整版本文字及窄布局宽度、可见文字留白、目标尺寸、文字垂直偏移和125% DPI 点击锚点；它明确不包含完整生命周期场景。

此前隐藏窗口驻留测试的间歇失败已定位到测试夹具：背景终端启动的窗口在原生隐藏后仍可能保留线程活动窗口状态，迟到的失活通知在新菜单激活时将其关闭。测试等待前一个菜单的 Closed 事件，在隐藏后通过一个临时屏幕外原生窗口明确交接活动状态，销毁该窗口并检查主窗口已隐藏、失活，再按真实入口排入 Dispatcher。`SetActiveWindow(NULL)` 在该背景输入队列中无法可靠完成交接，因此没有用它替代前置条件。补齐测试流程后，正式包完整菜单生命周期检查连续通过四次，另有16项界面回归通过；无需改变应用菜单行为。

便携程序在原目录就地更新，程序和 Data 保留本地忽略目录备份。部署核对运行时就绪、Shell 连接、实际菜单窗口与构建哈希；窗口截图仅保留在本地，不随源代码上传。
