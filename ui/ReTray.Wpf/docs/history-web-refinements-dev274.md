# 历史胶囊同行及网页细节（dev.274）

## 当前修改

- 网页的图表容器、指标卡、历史片段、Mesh 节点与数量胶囊、角色/连接标签、统计范围提示统一使用与时长胶囊相同的柔和阴影。边框变为透明但保留占位，原文字/图标颜色、基础尺寸及圆角不改。
- 网页图表绘制区右内边距从16改为24 CSS px，只缩小曲线/网格有效宽度，不改图表容器高度178或指标高度60。
- 既有窄屏单页模式（小于900 CSS px）固定五分钟，隐藏范围滑块；宽屏保留1/5/10选择，往返窄屏后恢复宽屏原选择。软件的统计范围不受影响。
- 顶部更新时间为 `HH:mm:ss 更新`，单行且不截断时间。窄屏的设备胶囊选中与普通状态底色一致，宽屏选中态保持。
- 网页文字默认不可框选，IPv4/IPv6信息卡及其全部内容允许选择复制。网页路由器刷新按钮移除，数据仍自动更新。
- 触屏按下设备胶囊时，独立按压状态同时缩放和加深遮罩；抬指、移动超过阈值、取消或失去窗口焦点清理状态。避免 touch hover 样式盖掉变暗，亦不依赖浏览器延迟的 `:active`。
- Mesh 的固定77px伪元素连线移除。根据真实 parentNodeId、深度及卡片 layout bounds 生成SVG：起点贴合父卡下方圆角轮廓，终点进入子卡左侧中央。尺寸、缩放动画及不同回程文字不会改变连接关系，支持多级结构。

## 软件与网页历史布局

时长胶囊始终保留在日期区域右侧居中，禁止整体移动到下一行，文本仍不换行。

宽排维持原 marker24、标签62、列间10、左右组间12和胶囊横向padding17。空间不足时先收紧 marker、间隙与胶囊padding；日期标签、日期和时间只在左侧日期区域内部重新排布，不隐藏文字、不裁剪、不横向压扁字体。软件全部字号保留14；日期中的1/5普通空格仍按原Run保留。历史展开、虚拟化、颜色与材质不改。
