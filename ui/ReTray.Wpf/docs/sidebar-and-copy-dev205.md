# dev.205 可调侧栏与地址复制

- 设备行从 48 增至 56 高度，图标从 32 增至 36，内容留白同步调整。
- 网络信息采用三列并排显示；IP、MAC 各自紧邻复制按钮。复制完整原值，成功短暂提示“已复制”，剪贴板占用时提示重试。
- 中间分隔条可拖动调整侧栏宽度，也支持键盘微调。范围为 280–520，同时为详情区保留至少 600 的布局空间；缩小窗口时自动收窄侧栏。
- 顶部“收起侧栏／展开侧栏”完全隐藏或恢复侧栏及分隔条，当前运行期间恢复收起前宽度。隐藏时详情面板保持正常外边距。

验证：Release 0 警告／0 错误；通过真实按钮 Click 路由验证复制目标（使用注入接收端避免污染用户剪贴板）；调整宽度后收起／展开回归；最小窗口布局及明暗主题渲染；设置和快速反向筛选回归。
