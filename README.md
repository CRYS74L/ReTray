# 托盘图标助手

独立 Windows 托盘管理软件。保留原软件的图标注册身份、消息闪烁与原生菜单，原生后台常驻，WinUI 3 小窗口按需打开。

当前开发版本：v0.1.12，WIP。主窗口为竖向小窗口，顶部三个选项卡，页面不再重复标题。主窗口和图标设置窗口采用低饱和度的云母 ALT；连接时显示多行占位符，正常运行时直接显示列表，出错时才出现提示。列表展示全部实时应用图标，每行具有外置显示/隐藏开关，34 DIP 紧凑单行、20 DIP 完整图标展示，元素垂直居中，并用从名称列开始的细分隔线分隔；不附加显隐字样或拖动竖杠。拖拽排序及自动排序只影响助手列表，Windows 托盘顺序由系统与用户管理，旧规则中的排序值也不再应用到原生托盘。图标在任务栏或折叠区的位置由 Windows 管理，软件不提供位置设置。图标本身响应左键、右键与双击，设置按钮独立。助手自己的托盘图标单击即可打开或唤起界面，右键菜单仅包含打开助手、重新启动和退出，从点击点右上方展开，并按监视器 DPI 原生渲染。重新启动先提交修改，再等待前后台退出，重新载入同一配置。运行时持续应用保存配置，退出时撤销图标和显隐策略，保留 Windows 当前顺序及配置。

根据当前产品要求，不包含窗口收起、密码保护、旧软件规则迁移或列表筛选。个人规则仅保存于本机用户配置，迁移辅助材料不进入仓库。

本机已验证：针对录屏 313 帧定位并修复排序越界后的恢复/移动重试，修复后 10 秒 600 帧检查未见原有周期消失/重排（排除初始展开动画），当前规则失败数为 0；真实通知目录与当前像素、GUID/非 GUID 身份、隐藏/定制/原生回调、闪烁空帧与恢复、后台退出与桥接卸载、Windows 原有系统控件；32 项核心契约；设置输入被拒绝后保持原配置；会话询问响应 3 ms、后台退出 446 ms；微信在面板中实际右键打开原菜单，隐藏后仍能打开；菜单获得前台焦点，并在返回助手或切换至桌面时关闭；新界面实际运行；显示/隐藏状态及提示更新顺序修复。自包含 MSIX 打包流程已跑通，使用开发自签名证书。

自启动使用 Windows 正式启动任务，可随安装版本更新；启用与禁用已在打包身份下跑通，任务操作具有三秒上限并响应退出。手动显示/隐藏会解除该图标的活动隐藏规则，避免开关被立即反转。同值提示/显隐不重复写入；局部修改保留其他策略，失败不会触发后台高频重试。

所有选项菜单由原选框下方展开，选框文字保持可见，菜单与窗口采用相同的云母 ALT 和统一字体；设置名称与开关同排。主窗口和二级窗口使用统一灰色悬停窗口按钮，深色云母采用较明亮的中性底色。主窗口最小尺寸为 300×260 DIP，并移除最大化按钮。滚动条位于恒定边距内，需要滚动时始终可见，内容能完整显示时隐藏且不接收悬停；其有无不改变内容宽度，非悬停滑块宽度为 4 DIP，悬停为 6 DIP，中心位置固定，深浅主题采用柔和的低对比度颜色。常规态与悬停态采用 280 毫秒 Cubic EaseOut 动画，浅色悬停更深，深色悬停更亮，不出现箭头或外框。系统图标自动读取，系统图标与高级设置直接完整展示。所有设置自动应用和持久化，连续输入合并写入，关闭窗口和托盘退出都会提交尚未完成的改动；保存失败保留修改供重试，连接恢复后补齐初始化。

v0.1.9 已逐帧核对本轮用户录屏的 170 帧，定位到主窗口先变暗及弹层外框与内容缩放不同步；弹层在布局准备后固定尺寸显示并淡入。修复后的 60 fps、300 帧录屏未见原有缩放跳变或浅色闪回。实机缩窗确认 125% 缩放下最低为 475×500 像素；真实列表拖拽改变助手顺序但不改变任何原生图标位置。受控原生测试确认闪烁空帧仍为空帧，原图预览保留最近有效源图，跨注册时清空缓存；同区域策略和退出不回写旧索引。真实微信在修复前已捕获 16 个有效帧及 19 个空帧，确认预览丢失原因，修复后的真实来消息场景待再次验证。

未完成的验收包括真实微信收消息后的自定义闪烁、真实登录/关机、长时资源采样；当前只对匹配已验证任务栏映像的系统启用写入。

v0.1.11 修复拖动时复用行的显隐回写，以及编辑器脱离父窗口时的主题回退。滚动条的 12 DIP 边缘空间现在由真实父布局分配，滑块始终处于所有祖先边界内，不依赖负边距越界；主窗口和二级窗口同步 WinUI 隐式宿主布局，避免固定尺寸内容在旧宿主中居中。实机确认深浅色滑块约 280 毫秒连续渐变，中心位置波动小于 0.08 像素；真实拖拽未修改其它图标的显隐，后台 16 项受影响回归通过。助手菜单在 125% 缩放下清晰显示并从右键点右上展开；实际重新启动前后台均更换进程，保留配置和资源。

本轮缩放录屏确认持续的滑块单独消失已消除；快速连续拖动边框仍会出现短暂整帧旧位置裁切及右侧、底部黑区，尚未修复，不作为通过项。用户暂缓排查的既有错误提示问题也保留。临时诊断和无效的预测尺寸、帧等待、全窗重绘候选均未保留到当前实现。

v0.1.12 修复按住滚动条、移出后释放时悬停态残留：同时处理子控件已经消费的指针事件、捕获丢失及取消，根据实际指针位置在原生处理后恢复状态。旧的排队状态不会覆盖较新的指针位置；无滚动内容及控件卸载时清空悬停态。实机浅色和深色下，窗口内移出与移到窗口外释放均恢复常规粗细及颜色，原有 280 毫秒动画保留。

v0.1.10 逐帧核对用户录屏的 128 帧，确认二级窗口存在先显示材质再淡入内容的问题；现等待渲染完成、合成提交及桌面合成同步后一次显示完整窗口。修复后的 60 fps、180 帧录屏首个窗口帧已包含完整内容，未见空面板、黑帧或尺寸跳变。显隐原先重放 75 条桥接指令，受控实机六次操作测得原生生效约 1156–1188 ms；现只处理目标图标，一条指令，实测 17.6–28.8 ms，RPC 30.5–31.4 ms。13 项后台回归、32 项核心测试及配置测试通过；助手图标隐藏后可立即显示，单击与原生菜单保持工作。移除顶部导航模板中隐藏侧栏残留的 320 DIP 最小宽度；125% 缩放下，主窗口与二级窗口在 375×325 像素（300×260 DIP）时无横向裁切，正常尺寸布局保持完整。

## 构建

使用 .NET 10、Windows App SDK 2.5.1、LLVM-MinGW 与 C++/WinRT。构建工具优先复用工作区 Common，机器快照、用户配置、图片、日志、符号与私钥均忽略。

```powershell
./build.ps1 -Target Agent
./build.ps1 -Target Bridge
./build.ps1 -Target CoreTests
./build.ps1 -Target SettingsTests
./build.ps1 -Target AgentVisibilityTests
./package.ps1
```
