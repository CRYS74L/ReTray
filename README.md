# 托盘图标助手

独立 Windows 托盘管理软件。保留原软件的图标注册身份、消息闪烁与原生菜单，原生后台常驻，WPF 原生小窗口按需打开，旧 WinUI 前端保留用于恢复。

当前开发版本：v0.1.41。主窗口为竖向小窗口，顶部按顺序提供托盘图标、系统图标和设置三个选项卡，页面不再重复标题。主窗口采用与 lan-device-monitor 相同的持久 Acrylic 材质，图标设置使用主窗口内的浮层；连接时显示多行占位符，正常运行时直接显示列表，出错时才出现提示。列表展示全部实时应用图标，每行具有外置显示/隐藏开关，34 DIP 紧凑单行、20 DIP 完整图标展示，元素垂直居中，并用从名称列开始的细分隔线分隔；不附加显隐字样或拖动竖杠。拖拽排序只影响助手列表，Windows 托盘顺序由系统与用户管理，旧规则中的排序值也不再应用到原生托盘。图标在任务栏或折叠区的位置由 Windows 管理，软件不提供位置设置。图标本身响应左键、右键与双击，设置按钮独立。助手自己的托盘图标单击即可打开或唤起界面，右键菜单仅包含打开助手、重新启动和退出，从点击点右上方展开，并按监视器 DPI 原生渲染。重新启动先提交修改，再等待前后台退出，重新载入同一配置。运行时持续应用保存配置，退出时撤销图标和显隐策略，保留 Windows 当前顺序及配置。

v0.1.41 重绘三个页面的加载占位符，按实际 28 DIP 图标列、34 DIP 行高和分隔线起点排列。托盘页包含名称、三点及开关，并随窗口高度补足占位行；系统页对应当前七行，仅输入法有三点；设置页对应开机启动、主题、语言和配置文件，分别绘制开关、两个下拉框和两个配置按钮。开关占位仅绘制胶囊剪影，不含内部圆点。占位符随浅色/深色变化，不含可操作控件；完成加载后切换真实内容，周期刷新保留已载入的系统列表，错误提示仍正常显示。

v0.1.40 修复 Store 应用更新后因版本安装路径变化而无法匹配旧托盘图标规则的问题。通过 Windows 包 API 校验包完整名称，并按包家族、资源标识及包内程序相对路径匹配同一应用；仍保留 GUID、UID、多图标角色、发布者隔离和冲突保护。旧配置、资源路径及持久键无需改写，当前已保存的替换图标可直接恢复。实现及验证见 [Store 应用升级匹配记录](docs/store-app-upgrade-v0.1.40.md)。

v0.1.39 将导出、导入胶囊的左右文字留白统一为 15 DIP，与下拉框的 13 DIP 内边距及 2 DIP 文字偏移之和一致。两个按钮共用样式内边距，保持现有字号、高度、主题表面与交互。

v0.1.38 修正 P3 开机启动图标的渲染比例：保留方案图中的 SVG 留白与线宽校准，不再将电源轮廓强制放大至 20 DIP，也不再通过几何相减削细圆弧。按用户最新要求，在 P3 比例基础上小幅放大 7.5%。Ionicons 原始圆弧与竖线轮廓保留；其他三个设置图标及列表布局保持不变。新增已选 P3 参考图的比例与圆弧连通性回归，覆盖 100%、125%、150%、200% 及放大检查。

## 构建

使用原工程 .NET 8 WPF、LLVM-MinGW 与 C++/WinRT。保留的 WinUI 前端使用 Windows App SDK 2.5.1。构建工具优先复用工作区 Common，机器快照、用户配置、图片、日志、符号与私钥均忽略。

```powershell
./build.ps1 -Target Agent
./build.ps1 -Target Bridge
./build.ps1 -Target CoreTests
./build.ps1 -Target SettingsTests
./build.ps1 -Target AgentVisibilityTests
./package.ps1
```
