# dev.216 窗口按钮参考图归一化修正

对用户两张截图按圆钮直径归一化测量，而非直接比较放大图与小图：颜色和总体占比接近，但原黄色横杠在实际栅格化后宽度约为圆钮 36%、高度 12%，参考约为 38.6%、9.1%；绿色几何的转角及斜边也有偏差。

本次：
- 黄色横杠改为圆头路径，宽度 7.64 DIP、笔画 1.82 DIP。
- 红叉笔画同步至 1.82 DIP，继续独立透明叠加。
- 绿色形状根据参考暗色区域轮廓拟合曲线，替换上一版近似路径。
- 圆钮与符号共用同一 20 DIP 绘制区域，关闭局部布局取整及像素吸附，避免各自取整。
- 中心间距由 28 调为 27 DIP，接近参考约 1.35 倍直径。

继续保持无底座、Windows 排序及仅悬停显示；底层材质未变。

验证：Release 构建零错误/警告；Apple controls 中符号居中、悬停/移出、焦点切换及浅深色布局回归通过；已从 WPF 控件直接生成 11 倍放大验收图 .tools/ui-dev216/controls-enlarged-proof.png（不是实际屏幕尺寸截图）。已发布到本机，663 个发布文件 SHA256 一致。
