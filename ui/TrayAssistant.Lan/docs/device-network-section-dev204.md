# dev.204 设备信息与容器圆角

- 连接类型、IP 地址、MAC 地址迁入详情页独立的“网络信息”三行卡片，绑定当前选择设备。标题区不再重复 IP 与 MAC。
- 设备列表移除连接类型及在线／离线文案和圆点，只保留图标、名称、速率。外层胶囊最小高度从 64 改为 48，图标从 40 改为 32，并调整上下留白。
- 参考用户提供的外观设置截图：普通外层面板使用 28 圆角，主要内容卡片使用 24，内层内容容器按体量采用 16–20；胶囊继续按高度的一半计算。以上为 WPF 桌面适配值，不标注为 Apple 官方统一半径。
- 保留字体层级、网速计算、设备选择逻辑与既有悬停动画。
