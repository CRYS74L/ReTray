# dev.209 窗口与统一侧栏调整

- 移除独立标题行和外围空隙，隐藏 Windows 11 DWM 边线，保留原生圆角和边缘缩放。
- 内容区右上角设置黄、绿、红窗口按钮，依次最小化、最大化/还原、关闭；关闭沿用原有托盘策略。顶部空白可拖动，双击最大化/还原。
- 设备列表与筛选胶囊等宽；预留独立 14 DIP 滚动条槽，并覆盖系统滚动条最小宽度，避免裁剪。
- 网络信息三组采用自然宽度与相等间隔，每组标题、值及复制按钮整体居中。
- 连接与更新时间同一行；收起侧栏保留一物理像素以上的分界线。
- 侧栏图标采用圆角分栏图形；软件图标和展开图标以 160 ms 淡入淡出衔接，保留悬停延迟、反向动画和减少动画设置。

Release 编译零错误、零警告。Apple controls 回归通过，覆盖真实布局、滚动、等宽、单行状态、收起分界线、图标变化、快速反向、键盘与浅深色 1180/980 布局。设置快捷键、快速列表反向、列表切换期间最小化和关闭到托盘回归通过。
