# dev.221 饱和度、靠近动画与侧栏底部入口

测算当前底色 HSV 饱和度：绿 #1DD66B 为 86.4%，黄 #FFD467 为 59.6%，红 #FF8071 为 55.7%。绿色确实明显更饱和。本次改为 #58D68D（58.9%），同步柔边 #46B879 和符号 #2F7D50；HSV 仅为数值比较，不宣称跨色相视觉饱和度绝对一致。

窗口按钮默认直径仍为 17 DIP。增加 4 DIP 靠近感应区域；放大至约 19.04 DIP（+12%）。放大、符号展开、透明度共享同一 GlyphProgress 动画时钟，时长与 Sine 曲线一致，反向衔接保持当前进度。透明感应区点击不触发窗口拖动，按钮仍单击执行。

按截图删除顶部“设备”入口和“设备列表”标题，路由器与设置以图标形式移至底部右侧。收起侧栏的对应图标也移至底部，整条窄栏仍点击展开。
