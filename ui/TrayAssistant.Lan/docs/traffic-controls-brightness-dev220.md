# dev.220 窗口按钮小幅缩小、提亮与对称显隐

- 直径由 18 调整为 17 DIP，中心间距由 25 调为 24 DIP。
- 以原收回节奏为基准：出现/消失几何进度均 100 ms，透明度均 80 ms；Sine EaseOut 与 EaseIn 互为时间反向，保持中断连续和减少动画设置。
- 面色/柔边成组提亮：绿 #1DD66B / #12BE59，黄 #FFD467 / #DEB64F，红 #FF8071 / #D96A60。
- 符号改由每个按钮的 Foreground 驱动：深绿 #08763B、暖金 #967020、半透明暖红 #99671D15。删除固定旧色笔画；克隆画刷后冻结缓存笔，避免冻结调用者的共享画刷影响渲染刷新。

验证：构建零错误/警告；多 DPI 像素居中、悬停反向、中间帧、归零、配色顺序与无提示框回归通过；检查 WPF 控件放大渲染和动画时间采样。安装并打开 dev.220，663 发布文件 SHA256 一致。原有单击功能与底层材质未修改。
