# dev.218 窗口按钮排序、尺寸与录屏符号动画

依据用户 ScreenRecording_09-30-2026 07-05-48_1.mp4，60 fps 逐帧检查（原片含旋转元数据）：约 1.02–1.42 秒符号由中心逐渐展开；约 1.75–1.85 秒明显收回。将圆钮整体缩放与符号相对圆钮的变化分开观察。

符号展开约 400 ms，淡入 120 ms；收回约 110 ms、淡出 100 ms。线条从中心伸展，双三角由中心聚合逐渐分开，圆钮尺寸全程恒定。按系统减少动画设置关闭动效。反向时从当前进度衔接，完成后移除动画时钟，旧完成回调用代次号隔离。
