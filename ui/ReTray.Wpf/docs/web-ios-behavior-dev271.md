# 网页平台与桌面行为审查（dev.271）

本轮以前一版本 dev.270 和 2026-10-05 08:43:47 录屏为基准。录屏为 8.77 秒、约 60fps，共提取 526 帧；先看整体切换，再逐帧检查 6.23–6.82 秒的设备切换。第 389 帧附近，旧设备历史内容在退出前清空，下面的内容提前上移。修改限制在网页及静态资源路由，桌面正常材质、布局和用户记录不改。

## 当前网页要求

- 背景和内容卡片采用用户提供的 iOS 截图：浅色 `#F2F2F6` / `#FFFFFF`，深色 `#1C1C1D` / `#2C2C2D`。这是内容表面颜色，不模拟透过桌面壁纸的黄色。
- 软件图标、蓝色主题色、上传橙色、设备图标底色、正文/辅助文字和小标题颜色沿用桌面 ThemeService；iOS 参考只调整背景和内容表面，不替换既有品牌或文字配色。
- 网页没有外层窗口边框、圆角或标题栏空白。宽屏两栏之间用一条浅分隔线，窄屏直接展示内容。内部卡片继续保留圆角。
- 网页取消整个设置页面及所有入口。主题只跟随访问设备的 `prefers-color-scheme`，忽略旧的手动主题缓存和桌面主题设置。旧 `#settings` 链接回到设备页/列表。
- 不展示网页无法操作的开机启动、Windows 通知、免打扰、凭据、刷新频率、设备编辑/移除、路由器重启、LAN 开关。只保留设备信息、流量、历史、网络/Mesh 信息及可用的刷新读取。
- 窄屏无返回按钮，使用浏览器历史支持系统侧滑返回。点击、触摸和程序恢复焦点不出现额外描边；真实键盘导航保留控件内部的主题色焦点反馈。
- 再次进入详情从顶部开始；点击当前已展示设备保持原页面，不重复播放切换。
- 保留原卡片盒模型：边框使用透明颜色而不是删除，防止内部上下 margin 合并到卡片外。图表 178、指标卡 60；流量内边距 16/18 加原边框；三条同排历史的外卡约 248、每条 68、间隔 8（125% DPI 实测有亚像素差异）。历史统计片段采用透明背景和描边，不填灰色；展开按钮与片段使用同组描边。
- 断点取消会统一重置页面、占位及列表的基础透明度/变换/层级，避免慢请求窄→宽→窄或入场宽→窄→宽留下永久透明的页面。

## 行为差异与修复

| 审查项       | dev.270 差异                                   | dev.271                                                                                                                   |
| ------------ | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 页面切换时序 | 顺序退出 260ms，再延迟 120ms 入场，总约 1160ms | 新旧页面重叠；旧页退出 260ms，新页延迟 120ms 后透明度 720ms、位移/缩放 780ms，总 900ms                                    |
| 动画参数     | 用近似 Bezier，设备入场 Y18                    | 直接采样 WPF Cubic InOut / Quintic Out；页面入场 Y18，设备/紧凑页入场 Y16；设备切换 150+450ms，透明度按 720/780 比例完成  |
| 退出内容稳定 | 提前清空旧历史 DOM                             | 请求预取不改旧视觉树；退出后才切换数据，并阻止过渡期间轮询改写列表/详情                                                   |
| 慢请求       | 动画完成 cancel 后旧内容恢复                   | 保持退出后的透明度/变换，导航接管时恢复；用 500ms 延迟请求验证                                                            |
| 动画布局     | 屏幕缩放后尺寸写回布局                         | 使用 offset/client 布局坐标；变换只作用视觉。进入前解析自适应列，滚动条采用覆盖层                                         |
| 左右间距     | 有滚动条时右侧预留宽度改变                     | 详情无滚动条占位，出现/消失都不改变内容宽度和左右边距；设备列表保留自身预留规则                                           |
| 分类筛选     | Y10 淡入，恢复旧选择                           | 旧/新列表 X±340 左右滑动并交叉淡入淡出 480ms；选择目标分类首项                                                            |
| 滚轮         | 列表积压上限与详情相同                         | 列表步长 170、积压 340；详情步长 180、积压 360；均 400ms Quadratic Out                                                    |
| 历史展开     | 时长接近但 easing 不同                         | +15 / 收回3，420ms Quintic Out / 320ms Cubic InOut；保留日期空间及同排时长规则                                            |
| 浏览器返回   | 缺少退出生命周期、跨断点可能空白               | 返回列表有退出/进入动画；重复 popstate/hashchange 去重；窄屏返回后放大仍能恢复详情                                        |
| 触屏提示     | 点击后 cursor、触摸捕获、模拟 hover 残留       | 触摸结束释放捕获；滚动、拖动、切范围/设备/页面清除图表提示；统计胶囊触摸抬指不被 mouse-leave 规则误关，滚动时跟随卡片淡出 |
| 图表时间窗口 | 用 serverTime 移动窗口                         | 61/301/601 固定整秒槽，以最新成功采样为右端；保留服务器时区                                                               |
| 图表悬浮     | 空槽借用远处真实采样                           | 选对应时间槽，空槽不提示；键盘可在真实采样间移动                                                                          |
| 曲线/横轴    | 缺样本切线，均匀标签                           | 与桌面相同的二次曲线，跨缺失槽连接真实点；原生 nominal/pixel step 标签；不虚构零值                                        |
| 图表提示位置 | 横向百分比定位                                 | 点右侧 12px，不够则左侧，窄屏边界安全；单样本点、标记圈遵循桌面参数                                                       |

## 验证

- Release 构建、GET/HEAD-only HTTP/凭据白名单/局域网安全回归。
- `node --test tests/web-chart.test.mjs tests/web-desktop-parity.test.mjs tests/web-motion.test.mjs`：16 个测试覆盖固定采样槽、缺失方向、时区、曲线、提示位置、单位与日期空间、DPI 舍入、原生动画数学和时序。
- Chromium 宽度 320、380、390、430、500、600、852、899、900、1218；浅/深色及实时系统主题切换；控件不缺失、根页面不横向溢出、无不可操作设置、无运行错误。
- 浏览器逐帧检查重叠切页和布局宽度；旧历史退出期间不删行；慢响应不重新显示旧页；滚动条出现/消失不改变宽度；快速导航、历史展开、跨断点恢复。
- Chromium 与 WebKit 触屏模拟：点击图表/胶囊、滚动关闭、历史返回、无触摸焦点圈、再次进入从顶部。Chromium 另检查实际触摸拖动产生的滚动。此处不是 iPhone 真机认证。
- WebKit 截图工具会临时注入样式，被网页严格 CSP 拒绝；此问题属于截图工具阶段，未放宽网页 CSP。WebKit 流程单独在不注入截图样式的条件下检查控制台和交互，截图证据使用 Chromium 及内置浏览器。

颜色和层次以用户截图为准；内容/导航层次同时参考 [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)。本实现不声称浏览器 CSS 等同于原生 Liquid Glass 的光学效果，也不改变 Windows 客户端设计。
