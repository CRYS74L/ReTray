# 选项说明

## 字体

界面正文与符号字体编译为 WPF Resource，分别使用内嵌 Microsoft YaHei UI 名称的文字资源与 Segoe Fluent Icons。文字资源取自原工程，其字形为用户替换后的苹方字形。助手的原生托盘菜单使用 Windows 菜单字体；系统文件选择对话框与原应用的托盘菜单由系统或原应用渲染。

## 应用图标的更多设置

- EXE / DLL 图标序号：选择自定义资源文件内的第几个图标，从 0 开始。适用于包含多个图标的 EXE / DLL；ICO / PNG 等图像无需使用此项。
- 交换左右键：互换该应用托盘图标的鼠标左键单击与右键菜单动作，不影响其他程序的鼠标设置。当前实现不交换双击与键盘动作。
- 不活动后隐藏：以图标图像最近变化及最近操作中较新的时间计算闲置，达到秒数后隐藏。0 关闭，最大 86400 秒。图标持续变化会保持活跃；不按进程 CPU、窗口焦点或整台电脑空闲时间判定。手动切换显示/隐藏会解除该项；既有常显规则具有优先权。
- 快捷键：为该原应用的托盘图标注册组合快捷键；Backspace / Delete 清空，原应用图标存在且助手运行时可调用。冲突时注册不会成功。
- 快捷键动作：从左键、右键、左键双击、右键双击中选择原应用交互。实际结果由原应用实现；例如右键调用原应用菜单，不为原应用添加未实现的动作。

助手自身图标使用自己的单击打开和简洁右键菜单流程，编辑页只提供已支持的图标及提示修改。

## 系统图标

通知指任务栏的通知铃铛/通知中心图标；隐私指示器指系统关于麦克风、摄像头、位置使用的动态图标。这些选项只处理对应独立图标的可见性，设备权限与通知接收由 Windows 管理。

当前只在 system.read 返回对应控件实例时启用开关。未识别时禁用，可能是当前没有独立控件或当前适配尚未覆盖；保存的偏好不因此视为已执行。助手不创建旧版替代图标。

## 高级设置

- 助手窗口置顶：将助手窗口保持在其他普通窗口上方。
- 隐藏开始按钮：隐藏任务栏开始按钮，保留开始菜单的系统功能与 Win 键入口；关闭或退出会释放隐藏策略。与系统图标“开始”属于重复入口，当前保存为不同策略字段；同时相反配置时，随后应用的系统图标策略会覆盖前者。
- 任务栏不透明度：0 至 255，作用于当前管理的整个任务栏窗口，包含按钮、文字、图标。128 约为一半；255 释放助手的透明度覆盖并恢复接管前状态。
- 自动按名称排序：按程序可执行文件名排序助手列表，不改变 Windows 托盘顺序；手动拖放会关闭自动排序。
- 打开助手快捷键：全局组合快捷键，用于打开或唤起助手界面；Backspace / Delete 清空。
- 导出配置：生成包含设置、图标规则及自定义图标资源的 JSON，便于备份及迁移。
- 导入配置：替换当前规则与偏好，恢复包内图标资源；导入前明确告知覆盖范围，旧有效配置自动保留为备份。

## 状态字段

- 后台版本：判断运行的是哪个原生后台版本。
- 连接状态：判断后台与原生托盘桥接是否连通，不代表全部偏好均已应用。
- 累计源事件：当前桥接会话观察到的受支持原应用托盘事件数量，用于调查频繁更新。不是图标数量或消息数量。
- 回调 p95：最近最多 512 次源事件中，助手在 Windows 原始处理返回后的追加处理耗时的近似第 95 百分位，单位微秒。用于分析桥接开销，不衡量整个程序的界面帧率或用户交互延迟。
- 后台 PID：用于定位进程、日志和资源占用，重启后会变化。
- 配置恢复：本次启动是否因为主配置读取失败使用了备份或默认配置；false 也可能是正常首次启动，不是保存状态。
- 快捷键冲突：原生注册失败的动作与错误。
- 任务栏设置：任务栏效果与系统图标策略合并的结果，可能因某个独立控件未识别而部分未生效。

目前状态页偏向开发和故障诊断；普通用户日常主要关注连接、未生效偏好与快捷键冲突，事件计数、PID、p95 可供排障时查看。
