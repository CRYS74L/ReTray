# dev.201 控件内容与反馈核查

用户参考页面的“聊天／工作”分段样式实际为 14px、500 字重，未选中项采用灰色并在悬停时转为主文字色。本项目采用微软雅黑，取消原有 SemiBold 和计数的单独加粗，以 Normal 保持较轻的实际字面；不把不同字体的相同数值视为相同视觉效果。

本次检查范围包括 App.xaml 的共享按钮、输入框、下拉框与时长徽标，AppleControls.xaml 的分段和开关，以及 MainWindow.xaml 的设备条目、详情状态、路由器状态、历史记录、设置和操作按钮；托盘菜单仍是菜单行，不作胶囊处理。

| 区域 | 处理 |
| --- | --- |
| 两处分段控件 | 标签和计数均为常规字重；未选中悬停转主文字色，移开恢复；选中状态不被悬停改变 |
| 设备条目右侧 | 状态与速度在至少 68 宽的区域内居中；内容右侧留白增至 24，脱离外侧弧边；设备栏加宽 20，补回名称空间 |
| 条目状态标签 | 48×24，12 字号；两行内容统一居中排列 |
| 历史时长 | 28 高度、12 字号、左右 14 留白，最小宽度 56；按内容自适应宽度 |
| 详情及路由器状态 | 28 高度、12 字号、左右 14 留白，垂直居中 |
| 设置输入／下拉框、复制链接 | 保留已验证的 40 高度与等高对齐，未继续仅修改圆角 |
| 顶部及其他操作按钮 | 核查文字与端部留白，保留上一版 36 高度体系与明确的局部尺寸 |

验证：Release 构建；分段最终文字字重、颜色与悬停进入／退出状态断言；带多设备及真实长度时长样本的 WPF 渲染；明暗主题与最小窗口布局；设置快捷键及反向筛选回归。截图与安装备份保存在本地忽略目录，不提交真实设备数据。
