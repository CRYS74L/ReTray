# 自身托盘菜单的原生调节候选

根据用户从 HTML 调节台导出的 v1 参数，将自身托盘菜单改为独立模板。其他下拉框保留原有尺寸。

| 项目 | DIP 值 |
| --- | --- |
| 宽度 | 随最长文字自动计算 |
| 面板圆角 / 描边 | 15.75 / 1.5 |
| 面板左、上、右、下内边距 | 2 / 2 / 2 / 2 |
| 行高 / 每项上下外边距 | 30 / 0 |
| 高亮圆角 | 40，在 30 行高下按胶囊形显示 |
| 字号 / 字重 | Noto Sans SC 12.75 / Regular |
| 文字左右内边距 | 11 / 11，保留原始字形边缘补偿 |
| 文字垂直偏移 | -1 |
| 阴影模糊 / 距离 / 不透明度 | 22 / 6 / 7% |

逐项微调和额外项间距均为 0。深浅色配色、悬停过渡时间、语言标签、点击锚点和菜单关闭行为保持原参数。

原生描边使用标准 WPF Border，保留 1.5 DIP 厚度，避免共用 RoundedCardBorder 将其取整。简体中文目标面板尺寸约 80.03825 × 97 DIP，最长文字可见左、右留白均为 14.5 DIP。

这是等待用户原生效果确认的本地候选；数值版本用于 EXE 标识，Git 标签使用开发后缀，不推送 GitHub。

验证使用与便携版一致的 .NET 8 运行时。调参候选可用 `--appearance-only` 单独检查可见文字留白、目标尺寸、文字垂直偏移和125% DPI 点击锚点；它明确不包含完整生命周期场景。

此前完整生命周期回归在隐藏主窗口后的菜单驻留场景出现过间歇失败，尚不能宣称完整回归全部通过。测试前台激活和实际 Shell 点击的差异仍需核查；实机菜单可打开的证据不能替代该回归。此候选先供用户检查外观，最终推送前继续处理该问题。

便携程序在原目录就地更新，程序和 Data 保留本地忽略目录备份。每轮候选通过运行时就绪、Shell 连接和实际菜单窗口观察验证；窗口截图只保留在本地，外观仍待用户确认。
