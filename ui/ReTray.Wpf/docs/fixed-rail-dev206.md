# dev.206 固定导航栏与设备栏动画

按照用户最后的澄清，原应用顶栏改为独立的左侧窄导航栏，始终可见且不能收起。设备栏位于它右侧，保留拖动调宽，并能独立收起到零宽。窗口原有最小化、最大化与关闭控件保持不变。

固定栏包含设备主页、设备栏展开／收起、路由器、设置；底部连接指示点的提示包含连接状态和最后刷新时间。浏览器参考只读取了用户指定 ChatGPT 页面的 DOM 和加载的 CSS，并实际收起、展开；观察到其折叠导航保留窄图标栏。本实现没有声称读取其未公开源码，也没有将参考页面的具体尺寸直接当作 WPF 的规范。

设备栏宽度使用 260ms EaseOut 过渡，内容同时淡入淡出；动画期间保持内容布局宽度，通过裁切避免文字反复换行。快速反向从当前宽度继续，旧动画结束回调不能覆盖新状态；调整窗口大小时按新边界稳定布局。关闭系统动画时直接切换。固定导航栏的位置与宽度不参与动画。

设备胶囊保持 56 高度，36 圆形图标背景与外部胶囊左端同心，左、上、下均留 10 个逻辑像素。局部关闭布局整数取整，避免 125% 缩放时把 12.5 像素间隔分别舍入成 12 与 13。网速数值、空格和单位使用一个 TextBlock 的三个 Run，统一 BaselineAlignment，不再分别垂直居中两个不同字号的 TextBlock。

验证覆盖：Release 0 警告／0 错误；实际布局坐标的三边等距；网速单行基线；设备栏动画中间帧、快速反向、宽度恢复；固定栏全程可见且位置不变；设备栏收起后打开设置并返回详情；窄窗口、明暗主题；既有设置、复制和反向筛选回归。截图、安装备份保留于本地忽略目录。
