## 网页界面

- 详情一级卡片与设备栏普通胶囊共用底色；嵌套表面逐级提亮。浅色为 `#F7F7FA → #FCFCFD → #FFFFFF`（给白色上限留出层次），深色为 `#2C2C2D → #3A3A3C → #48484A`。按用户最新参考图，历史统计片段使用第二级提亮底色，时长胶囊使用第三级底色与柔和阴影，取消可见描边；仍保留透明边框的几何占位。
- 保留原图标、正文、辅助文字、小标题配色，以及卡片宽高、内边距和透明边框盒模型。
- `IMG_4058.png` 原图宽 1284px，对应 428 CSS px 的 3×屏幕；多个白色设置分组左边界 60px，圆角轮廓拟合约 80px，即约 26.67 CSS px。矩形卡片采用该半径，胶囊和圆形仍保持各自形态；不改变尺寸。
- 图表圆点只和采样信息浮窗一起显示。SVG visibility 可被子元素覆盖，因此关闭浮窗时显式隐藏子圆点；移除不依赖浮窗的独立单点圆圈。
- 横屏侧栏固定展开，移除展开/收起按钮和窄轨；保留分界线鼠标拖动/键盘调整宽度。操作从实际有效宽度开始，视口限宽时也立即响应；取消捕获不会留下拖动状态。
- 路由器入口是顶部软件图标和名称组成的点击区域。状态灯及更新时间放到顶部右侧。底部路由器入口和整个 footer 移除，列表下沿不再渐变；系统安全区仍保留。

## 软件和网页共用 Mesh 过滤

- 只过滤展示列表与计数，不删除设备或上下线/流量历史，不改变提醒偏好、材料或桌面布局。
- 当前 Mesh 拓扑主/子成员的可靠 MAC 优先匹配，允许大小写/分隔符规范化；不能仅凭“路由器”类型或名称就隐藏。
- 节点无可靠 MAC 时，合法 IP 只能匹配唯一在线、原始身份为路由器的设备；识别后绑定 MAC，所以离线成员仍可隐藏，DHCP 接替 IP 的手机不被隐藏。
- 完整成功拓扑移除成员后恢复普通设备展示；暂时失败保留已证实成员身份，禁用无效 IP 证据。无有效身份的 graph 不当作成功拓扑。
- MonitoringService 统一自动拓扑请求与缓存：连接后获取、每分钟刷新，不依赖开启网页或点击路由器页面。UI dispatch 更新桌面计数/列表，Web snapshot 同步过滤。Web 开关/页面刷新共用请求，停止及关闭取消工作。
- 不新增持久化成员集合；重新启动从当前拓扑识别。没有 MAC 且启动即离线的未知节点，不用过期 IP 猜测身份；明确不同 MAC 的同 IP 也不强行当成同一设备。

## 验证

- Node 图表/日期/DPI/动画数学测试；`--mesh-membership-regression` 合成测试；既有 `--web-access-regression`；Release 构建。
- Mesh 回归覆盖主/子成员、在线/离线、普通路由器、旧 IP 接替、拓扑到达即时更新、成员退出/失败恢复、网页关闭时自动更新、原始记录及隐藏详情历史保留、请求去重与停止取消。
- Chromium/WebKit 触屏模拟在 popstate 后连续采样列表状态：不能回到详情、不能有侧栏入场/缩放；滚动关闭浮窗后 SVG 圆点必须隐藏。测试不声称 iPhone 真机复测。
- 320–1218 CSS px 浅/深色、标题与图标原色、卡片尺寸与边距、层级/圆角、顶部入口与状态、无底部渐变、920px 受限视口拖动/键盘调整、快速导航、慢响应、断点中断回归。
