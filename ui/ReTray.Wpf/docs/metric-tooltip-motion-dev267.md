# 统计区间提示退出动画与滚动定位（dev.267）

逐帧检查用户录屏 `Desktop 2026.10.05 - 05.58.27.24.DVR.mp4`（60 fps）：约 0.73 秒鼠标离开时提示直接消失；约 2.15 秒起卡片上移，提示继续在原屏幕位置消退。

dev.266 增加了关闭触发，但直接关闭 IsOpen 不能保证退出动画，也没有管理原生提示弹窗消退时的屏幕坐标。

仅两张总量卡片改用 MetricRangeToolTip，沿用同一个样式和模板。关闭请求保留提示 120 毫秒，淡出其透明度；其间按定位卡片的实际屏幕位移移动提示自己的 HWND，保持打开时的相对位置。目标隐藏或卸载时立即结束；系统关闭界面/提示动画时不增加淡出。关闭后解除布局订阅。

只在退出时关闭该提示自己的原生 Popup 动画，防止自定义动画结束后再在旧坐标消退；真正关闭后恢复原有出现动画。使用公开逻辑父节点获取 Popup，不反射 WPF 私有字段，不修改系统设置。WPF 提示与 Popup 关系参考 [dotnet/wpf ToolTip 源码](https://github.com/dotnet/wpf/blob/main/src/Microsoft.DotNet.Wpf/src/PresentationFramework/System/Windows/Controls/ToolTip.cs)。

退出期间重新打开会取消旧完成回调，防止新提示被旧动画关闭。另覆盖系统提示服务已打开/同设备忽略重开请求的分支：通过目标的 MouseEnter 与 ToolTipOpening 恢复鼠标离开后的重开；滚动引起的 MouseEnter 不取消滚动退出。系统强制销毁提示窗口时同步打开状态，避免窗口已消失但 IsOpen 仍为 true。字号 12、内边距 2/4、胶囊圆角、日期数字 1/5 空格与波浪号两侧 1/2 空格、颜色及材质保持原样。

验证使用独立离屏窗口及虚构设备，不操作实际鼠标或设备记录。旧代码的渐隐断言失败；补充的真实 WPF 提示服务快速重开路径也先复现失败再修正。回归调用实际提示服务的显示、关闭、同目标与已打开分支，私有接口反射仅在测试中使用。修复后下载/上传、浅色/深色的实际滚动与平滑滚动检查退出期间水平及垂直相对偏差不超过 1.5 屏幕像素，同时检查中间透明度、最终关闭、重复打开、中断关闭、隐藏目标、出现动画恢复与字号/胶囊尺寸。Release 构建及缩放缓存回归通过。
