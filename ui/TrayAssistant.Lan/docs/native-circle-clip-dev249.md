# 原生窗口圆环裁剪修复 dev.249

此前的单控件轮廓检查没有覆盖实际窗口合成与裁剪，不能证明用户看到的圆环完整。本次在原生窗口中复现了圆环下沿缺口，并以相同位置的原生截图对照。

- 圆形按钮改为直接描边椭圆，填充与轮廓分别绘制。
- 轮廓向控件内部留出一个设备像素，保证底部抗锯齿覆盖不触及原生裁剪边界。
- 使用专用 `--history-native-ring-regression`，只检查缺口相关路径。覆盖六个滚动位置／像素相位；以真实窗口截图采样轮廓全周，不以孤立控件位图代替。
- 保留旧绘制方式的原生截图作为对照，并检查向上状态。没有重复运行不受影响的其他功能测试。

按钮命中区域、箭头旋转、分页与表单对齐不变。发布前构建并备份旧安装，发布后校验运行版本及全部部署文件 SHA256。
