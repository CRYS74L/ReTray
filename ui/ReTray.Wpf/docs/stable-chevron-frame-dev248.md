# 历史箭头与圆环绘制修复 dev.248

上一版箭头在 `OnRender` 中读取父按钮坐标，并在测试中主动调用了 `InvalidateVisual`。取消该调用后复现了箭头绘制异常，原测试遗漏了布局变化与缓存路径。

- 箭头改为覆盖整个按钮的固定绘制区域，只使用自身 `RenderSize` 的中心，移除渲染过程中的父级坐标换算。
- 在加载与可见性变化时按控件生命周期刷新绘制，保留 180 ms 旋转及中途反向连续性。
- 圆形按钮轮廓使用已验证的像素对齐圆角边框绘制，修正圆环下沿断口。
- 测试取消主动重绘，覆盖 1180 / 1181 / 1182 / 1191 / 430 DIP 的连续布局变化，采样圆环全周轮廓与箭头上下状态的实际笔画重心。

验证使用历史、浅深色外观、菜单对齐和响应式导航专项及原生窗口截图。每次十五条、完全展开才收起、表单笔画对齐与八 DIP 间距保持原有行为。未重跑历史全量旧控件套件。
