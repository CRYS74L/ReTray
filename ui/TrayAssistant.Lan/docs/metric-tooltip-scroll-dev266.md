# 统计区间提示滚动滞留修复（dev.266）

用户录屏 `Weixin 2026.10.05 - 05.36.06.22.DVR.mp4` 中，详情滚动使下载总量卡片移出鼠标所在位置，但统计区间提示仍停留在原来的屏幕位置。

此前提示只检查内容是否为空，没有跟踪定位卡片所在滚动容器的偏移。卡片随内容移动时，不能仅依赖鼠标移动产生的默认提示关闭行为。

仅下载总量、上传总量使用的提示样式启用滚动关闭：打开时订阅卡片祖先滚动容器的实际偏移变化，以及卡片的鼠标离开、隐藏、卸载事件；关闭时解除全部订阅。尺寸或内容范围改变但偏移未变时，不因该事件关闭提示。打开时目标已经不可见，也立即关闭。

保留现有字号、内边距、胶囊圆角、日期间隙、颜色及背景材质。

验证：

- 修复前，独立 WPF 回归窗口执行实际详情滚动后，下载总量提示仍打开，断言失败。
- 修复后，`--metric-tooltip-scroll-regression` 通过下载和上传、静止鼠标下实际滚动、反复打开、鼠标离开事件、平滑滚轮、卡片隐藏和隐藏后重新打开检查。
- `--resize-cache-regression` 通过。
- Release 构建无警告、无错误。

回归使用独立窗口与虚构设备，不操作用户鼠标，不读取或改写实际设备记录。鼠标离开分支通过路由事件验证；滚动分支使用真实 ScrollViewer 偏移及平滑滚动路径验证。
