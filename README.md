# 托盘图标助手

独立 Windows 托盘管理软件。保留原软件的图标注册身份、消息闪烁与原生菜单，原生后台常驻，WinUI 3 小窗口按需打开。

当前开发版本：v0.1.6，WIP。主窗口为竖向小窗口，顶部三个选项卡，页面不再重复标题。主窗口和图标设置窗口采用低饱和度的云母 ALT；连接时显示多行占位符，正常运行时直接显示列表，出错时才出现提示。列表展示全部实时应用图标，每行具有外置显示/隐藏开关；图标本身响应左键、右键与双击，设置按钮独立。助手自己的菜单仅包含打开助手、恢复托盘和退出。

根据当前产品要求，不包含窗口收起、密码保护、旧软件规则迁移或列表筛选。个人规则仅保存于本机用户配置，迁移辅助材料不进入仓库。

本机已验证：针对录屏 313 帧定位并修复排序越界后的恢复/移动重试，修复后 10 秒 600 帧检查未见原有周期消失/重排（排除初始展开动画），当前规则失败数为 0；真实通知目录与当前像素、GUID/非 GUID 身份、隐藏/定制/原生回调、闪烁空帧与恢复、后台退出与桥接卸载、Windows 原有系统控件；32 项核心契约；设置输入被拒绝后保持原配置；会话询问响应 3 ms、后台退出 446 ms；微信在面板中实际右键打开原菜单，隐藏后仍能打开；菜单获得前台焦点，并在返回助手或切换至桌面时关闭；新界面实际运行；显示/隐藏状态及提示更新顺序修复。自包含 MSIX 打包流程已跑通，使用开发自签名证书。

自启动使用 Windows 正式启动任务，可随安装版本更新；启用与禁用已在打包身份下跑通，任务操作具有三秒上限并响应退出。手动显示/隐藏会解除该图标的活动隐藏规则，避免开关被立即反转。位置超出当前可见列表时按边界处理，同值位置/提示/显隐不重复写入；局部修改保留其他策略，确定失败不会在后台高频恢复/移动。

未完成的验收包括真实微信收消息后的自定义闪烁、真实登录/关机、长时资源采样；当前只对匹配已验证任务栏映像的系统启用写入。

## 构建

使用 .NET 10、Windows App SDK 2.5.1、LLVM-MinGW 与 C++/WinRT。构建工具优先复用工作区 Common，机器快照、用户配置、图片、日志、符号与私钥均忽略。

```powershell
./build.ps1 -Target Agent
./build.ps1 -Target Bridge
./build.ps1 -Target CoreTests
./build.ps1 -Target SettingsTests
./package.ps1
```
