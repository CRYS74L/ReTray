# dev.234：窄窗口导航、设备列表与路由器页面

## 用户要求与实现

- 在线设备图标和圆底保留蓝色；离线设备改为灰色图标、灰色圆底。列表和设备详情同步处理。
- 删除设备类型说明、开机启动说明、局域网正常访问说明、刷新间隔单位说明、定时免打扰说明和设置页副标题。刷新选项直接显示 `1秒 / 2秒 / 3秒 / 5秒 / 10秒`，使用独立数值标签读取配置。真实错误、访问准备和复制反馈仍可显示。
- 定时免打扰关闭时，时间设置整行折叠；开启时显示，原时间值保留。
- 减小设备胶囊及底部圆按钮的按压暗层；侧栏展开/收起按钮改为悬停轻微压暗、按压加深，不使用提亮层。
- 继续使用固定版本 Lucide。摄像头改为圆形镜头的 webcam，笔记本改为圆角屏幕加底线的 laptop-minimal；插座使用同规格圆角外框与插孔适配图。桌面与网页共享生成源。
- 删除设备名称的重复 Tooltip。
- 列表过渡的平移、透明度和缓存只作用于 ItemsPresenter。滚动条保留在固定父层；去掉设备列表滚动条额外的上下边距及轨道内边距。
- 设备列表上下边缘使用 12 DIP 的透明渐变，按是否还有屏外内容启用。渐变按视口绝对坐标绘制，不覆盖滚动条；到达顶部或底部时对应边缘恢复完整显示。
- 收起后的侧栏保留两个可分别点击的圆形导航按钮，移除状态圆点。
- 路由器页重构为网络连接、Mesh 网络、路由器管理。IPv4/IPv6 使用独立信息卡，标签与值分层，长地址可以换行；重启仍需现有二次确认，不会在普通页面导航时执行。
- 最小窗口宽度降至 380 DIP、高度 560 DIP；宽度小于 900 DIP 时显示单页导航。先展示设备列表，点击设备进入对应详情，顶部按钮返回列表；路由器、设置入口采用相同导航。放宽后恢复双栏及原侧栏展开/收起偏好。
- 连接信息、流量卡、名称/类型输入、路由器凭据、时间输入及历史记录针对窄窗口重新排布，文字字号不随窗口缩小。
- 四项信息采用 4→2→1 列排列，避免中间尺寸出现 3＋1 的不均衡布局；额外复查 1132 DIP 和真实安装窗口。

## 保留的行为

内嵌字体和原文字字号保持不变（路由器重构区域按新信息层级排版）。设备详情仍为 150ms 退出、450ms 进入的两段式动画，总时长 600ms；设备列表保持 480ms。历史虚拟化继续保留完整数据及滚动范围。正常开发测试使用合成设备和隔离配置，不修改用户密码、设备资料或路由器状态。
