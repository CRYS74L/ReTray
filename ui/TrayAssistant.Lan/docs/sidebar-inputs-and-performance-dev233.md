# dev.233 侧栏、输入控件与切换性能

## 本轮调整

- 底部圆按钮保留原有背景提亮、描边和按压反馈，仅降低内部图标的悬停提亮幅度。
- 类型“空气检测仪”扩展为“监测设备”；具体设备的建议名称仍可为“空气检测仪”。旧配置通过显示层别名兼容，不覆盖用户已存配置。
- 继续使用固定版本 Lucide：监测设备采用 gauge，其他设备采用 cpu，电视采用 tv-minimal。平板保留 Lucide 轮廓风格、略微加宽，底部指示改为环形；桌面和网页由同一生成脚本输出。
- 侧栏按钮从 22 DIP 缩至 21 DIP。去掉将键盘焦点误绘制成填充悬停态的触发器，键盘焦点使用独立细描边。收起后始终显示侧栏图标，不再切换为软件标志。
- 修正 125% 缩放下约 1 个物理像素的布局舍入变化误中断侧栏动画的问题；真正的窗口尺寸变化仍可结束过渡并同步布局。
- 密码遮罩从实心大圆改为更小的项目字体圆点，已保存密码提示与正在输入的遮罩保持一致。
- 下拉菜单项继承所属下拉框的字体、字号、字重和实际高度；保留 dev.232 的宽度约束及文字起点对齐。
- 自定义名称的空值说明移入输入框占位提示；路由器地址、管理员密码、免打扰时间及局域网地址也提供相应提示。字段标题保留。提示不成为输入值，输入内容后隐藏；保存过密码时提示不会与遮罩重叠。

## 录屏及切换性能

只读取用户提供的原始录屏，原文件未修改。录屏为 2560×1440、60 fps、约 4.63 秒；列表局部帧差检查在约 0.933/0.950 秒和 1.683/1.700 秒发现连续近似重复帧，位置与详情内容替换阶段相近。

后台 WPF 复现中，100 条上下线历史原先一次生成约 700 个 TextBlock。新增 SessionHistoryPanel 与原页面外层 ScrollViewer 配合，保留完整内容高度，只生成可视区域及缓冲行。相同场景降为约 28 个 TextBlock，模型仍为 100 条，滚动高度仍为 7897.6 DIP。测试覆盖中部第 50 条、末尾第 99 条及记录数量从 100 减为 5 后的高度更新。

详情过渡期间暂缓修改参与动画的可视树，后台采样继续进行，结束后追上最新快照。详情动画仍为原有两阶段：退出 150ms、进入 450ms，总计 600ms；在线/离线列表动画保持 480ms。

同机后台 Rendering/Dispatcher 采样中，基线四次最大帧间隔为 1020.6/63.0/36.8/50.4ms，修改后为 24.0/37.0/26.9/33.3ms。该数据说明首次大规模布局阻塞及后续开销显著减少，不能等同于前台固定帧率承诺。
