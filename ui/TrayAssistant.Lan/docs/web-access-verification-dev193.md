# dev.193：仅保留局域网网页

用户撤销手机推送，要求开源用户无需域名、账号、证书、访问码或云服务，开启后直接用局域网链接查看。

## 改动
- 桌面设置仅保留开关、访问链接、二维码和复制链接。
- HTTP 只读服务仅绑定本机私有 IPv4 和回环地址；开启即允许同一局域网内可达设备读取信息。无登录步骤。
- 自动尝试可用端口，不结束其他程序。优先显示通向路由器的本机地址；没有局域网连接时明确提示仅本机可访问。
- 删除手机推送、订阅接口、WebPush 依赖、证书生成和下载、Service Worker 及通知页面。保留原 Windows 系统通知与免打扰。
- 旧配置中的已移除字段在正常保存时不再写回。旧 DPAPI 文件不再使用，保留以免擅自删除用户数据。

## 验证
- Release 构建零警告、零错误。
- `--web-access-regression`：直接 HTTP 查看、端口占用避让、纯只读接口、推送/证书路由消失、Host/Origin 拦截、启停、旧配置迁移、实际 WPF 控件精简及启动互斥。
- `--settings-shortcut-regression` 和 `--notification-once-regression` 通过。
- 侧边浏览器使用合成数据验证 390×844 竖屏详情、844×390 双栏、路由器与 Mesh 页面；无横向溢出和相关浏览器警告/错误。
- 独立审查发现自动恢复与关闭开关间的竞态，已将初始化接入同一互斥处理并通过实际 WPF 回归。

未声称在真实手机上验证跨设备网络连通。Windows 防火墙或访客 Wi-Fi 隔离仍可能阻止访问，程序不自动关闭系统安全保护。Cloudflare 仅曾只读查询，未创建任何云资源，当前功能无云依赖。
