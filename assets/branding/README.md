# ReTray 图标资源

这里保存已确定的四份图标主文件，以及 README 使用的描边展示副本，不包含设计迭代稿。

| SVG 主文件 | 使用位置 |
| --- | --- |
| `retray-color.svg` | EXE、程序目录、开始菜单、安装包、任务栏、自身托盘、窗口和界面内标志；透明背景 |
| `retray-black.svg` | 备用纯黑资源；不再用于默认托盘图标 |
| `retray-white.svg` | 备用纯白资源；不再用于默认托盘图标 |
| `retray-macos-white.svg` | 仅桌面快捷方式（`DesktopIcon.ico`） |

`retray-readme.svg` 是白色底板图标的说明页展示副本，增加淡灰色细描边并留出描边空间。
它仅用于项目 README，不参与 ICO 和软件包图标生成。

定稿参数保存在 `geometry.json`：环带宽 110、中心圆盘 R112、尖端 R5、转角 R66.5、
尖角延长 54.5，平滑圆弧 R133 / 24°，共 27 个独立的渐变色标。

PNG 为同名 SVG 的 1024px 参考渲染。`packaging/build-assets.ps1` 直接从 SVG
分别渲染每一个尺寸，生成多尺寸 ICO、包图标和透明任务栏资源，不从大 PNG 再缩小。
每个 ICO 包含 16、20、24、30、32、36、40、48、60、64、72、80、96、128、256px
共 15 帧。SVG 保留 G2 轮廓及矢量渐变。托盘按任务栏 DPI 加载尺寸，并在 DPI 变化后更新。
自身托盘图标有用户自定义替换时，以用户设置为准。
