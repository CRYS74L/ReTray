# 局域网网页与 Web Push

用户已选择 Web Push 并要求直接实现；不安装专用通知 App，不部署公网监控网站。

## 行为
- 桌面设置提供默认关闭的局域网访问开关、端口、访问链接、二维码、访问码及重置授权。
- 内嵌 Kestrel HTTPS 服务，只绑定本机回环及私有 IPv4；明文端口仅提供证书安装说明和公开 CA 证书，不提供监控数据或授权凭据。
- 自动生成独立 CA 与包含当前局域网 IP 的服务器证书。手机须手动信任 CA；不自动修改系统信任、不关闭防火墙。显示 SHA-256 指纹用于带外核对。IP 改变后重新应用服务以签发新证书，推荐 DHCP 地址保留。
- 网页只读呈现设备列表、连接信息、流量趋势、会话历史、路由器 IPv4/IPv6 和 Mesh 节点。窄屏列表/详情导航，宽屏双栏，系统深浅主题。数据来自现有监控，不按浏览器数量重复轮询路由器。
- 访问凭据使用高熵随机值，认证请求通过 Authorization 头；不进入 URL 查询、日志或推送内容。分享链接使用 fragment，网页立即清除 fragment。重置撤销所有订阅与访问码。
- 标准 Service Worker + Push API + VAPID。iOS/iPadOS 主屏幕安装与系统授权由用户完成。加密发送设备上下线和 IPv6 提醒，沿用当前免打扰及去重规则。
- DPAPI 保护持久化的服务器私钥、CA 私钥、VAPID 私钥、访问码和订阅。发送队列有界，HTTP 有超时，不阻塞 WPF UI/监控；404/410 删除过期订阅，失败不无限重试。
- 订阅只接受已知浏览器推送服务 HTTPS 地址及合法公钥，禁止重定向和任意目标请求。禁用访问时停止监听和推送；浏览器通知权限仍由系统管理。
- 界面区分“不支持”“未授权”“已订阅”“推送服务接受”“发送失败”；不能声称手机收到。通知只导航到本网站，离开局域网可收到推送但无法加载详情。

## 验证边界
自动验证认证、私有地址限制、服务启停、证书持久化、订阅校验、过期清理、负载加密发送、页面响应布局和关键交互；保留现有通知/流量回归。真实手机的证书信任、授权及锁屏到达必须由手机端验证，不能用模拟订阅替代。
