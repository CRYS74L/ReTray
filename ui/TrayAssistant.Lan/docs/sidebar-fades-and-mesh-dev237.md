# dev.237：侧栏边界、信息对齐与 Mesh 层级

## 本轮修正

- 撤销摄像头、插座的定制轮廓，恢复固定版本 Lucide `cctv`、`plug`，桌面和网页同步。
- 设备列表增加固定、裁剪到视口的渐隐承载层。发生裁切的边缘保持透明，渐隐长度随屏外内容距离连续增长到 36 DIP；不再通过提高边缘不透明度来减弱渐隐，避免残留一条硬切边界。滚动条不参与遮罩或左右平移。
- 点击收起侧栏的空白区域重新展开；点击其中的独立按钮继续执行其各自操作。
- 顶栏从 40 DIP 收到与按钮一致的 32 DIP，移除其下方 8 DIP 额外留白。保留透明的顶部/上角缩放命中区域，不改变窗口材质方案。
- 连接信息按照各组内容的自然宽度排列，将剩余空间放在组与组之间，第一组和最后一组贴齐内容区两端；窄窗口继续按可用宽度换行。
- 窄屏与横屏设备详情共用 150ms 退出、450ms 进入的时间参数，并统一 Cubic EaseInOut 退出、Quintic EaseOut 进入及透明度节奏。进入窄屏设置/路由器页时不再叠加另一套内部页面动画。
- 重启图标底色和按钮底色使用单独的红色资源，与蓝色设备图标底色采用相近的透明度和明度差；不连带改变删除设备等其他危险操作的样式。
- IPv4 恢复“连接类型、IP 地址、子网掩码、默认网关、DNS”的同级字段，移除放大的“互联网地址”展示。

## Mesh 关系与排版

原解析只读取 `graph.leafs` 的第一层。现在递归保留接口返回的树形父子关系，用每次拓扑快照内唯一的路径 ID 关联节点，不依赖可能重复的名称。

界面按主路由、子节点、多级子节点绘制缩进和连接线；只连接数据中存在的父子节点，不为缺少上游信息的对象编造关系。节点名称、角色、回程类型、IP、硬件型号和直连设备数量分层展示。

桌面宽度下设备数量位于右侧；窄卡片中转为信息下方的紧凑标记，避免挤压名称和 IP。节点连接线及卡片资源随浅/深色主题更新。
