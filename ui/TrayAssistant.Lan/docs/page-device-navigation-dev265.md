# dev.265：从设置返回另一设备时不显示旧设备

用户 3.305 秒、60 FPS 录屏中，设置页之后先出现 iPhone 13 Pro Max（A），完成退场后才显示门口摄像头（B）。对 1.55–2.05 秒片段逐帧核对，画面顺序为设置→A→B，帧图保存在忽略目录 `runtime-data/navigation-flash-dev265`。

鼠标预览事件此前在 ListBox 默认选中 B 之前调用 `ShowDevicesPanel`：页面首先显示仍选中的 A，随后的 SelectionChanged 又启动 A→B 设备动画。现在先提交点击行，SelectionChanged 在旧页面上更新 B 并发起一次页面过渡；同设备没有 SelectionChanged 时由预览事件导航。保留默认列表焦点处理、窄屏路径和原有动画时长。

页面入口完成回调还检查当前 RenderTransform 的归属，避免重置后续设备动画。此为动画归属防护；评审提出的回调抢占候选并未在快速点击检查中实际红灯复现，不把它描述为录屏根因。

验证：旧代码专用回归在第一个采样直接失败，A 可见且 opacity=1；修正后浅深色设置/路由器→同设备或 B，各 45 个动画阶段采样未暴露错误设备，标题绑定和终态正确。另覆盖入口开始后 20/850 ms 再选择 C，并持有旧 transform，最终停留最新设备。Release 构建 0 警告、0 错误；原响应式导航回归通过。测试使用独立离屏窗口与合成记录，不读取或修改实际监控数据。
