# 托盘图标助手

独立 Windows 托盘管理软件。保留原软件的图标注册身份、消息闪烁与原生菜单，原生后台常驻，WPF 原生小窗口按需打开，旧 WinUI 前端保留用于恢复。

当前开发版本：v0.1.20，WIP。主窗口为竖向小窗口，顶部按顺序提供托盘图标、系统图标和设置三个选项卡，页面不再重复标题。主窗口采用与 lan-device-monitor 相同的持久 Acrylic 材质，图标设置使用主窗口内的浮层；连接时显示多行占位符，正常运行时直接显示列表，出错时才出现提示。列表展示全部实时应用图标，每行具有外置显示/隐藏开关，34 DIP 紧凑单行、20 DIP 完整图标展示，元素垂直居中，并用从名称列开始的细分隔线分隔；不附加显隐字样或拖动竖杠。拖拽排序只影响助手列表，Windows 托盘顺序由系统与用户管理，旧规则中的排序值也不再应用到原生托盘。图标在任务栏或折叠区的位置由 Windows 管理，软件不提供位置设置。图标本身响应左键、右键与双击，设置按钮独立。助手自己的托盘图标单击即可打开或唤起界面，右键菜单仅包含打开助手、重新启动和退出，从点击点右上方展开，并按监视器 DPI 原生渲染。重新启动先提交修改，再等待前后台退出，重新载入同一配置。运行时持续应用保存配置，退出时撤销图标和显隐策略，保留 Windows 当前顺序及配置。

根据当前产品要求，不包含窗口收起、密码保护、旧软件规则迁移或列表筛选。个人规则仅保存于本机用户配置，迁移辅助材料不进入仓库。

本机已验证：针对录屏 313 帧定位并修复排序越界后的恢复/移动重试，修复后 10 秒 600 帧检查未见原有周期消失/重排（排除初始展开动画），当前规则失败数为 0；真实通知目录与当前像素、GUID/非 GUID 身份、隐藏/定制/原生回调、闪烁空帧与恢复、后台退出与桥接卸载、Windows 原有系统控件；32 项核心契约；设置输入被拒绝后保持原配置；会话询问响应 3 ms、后台退出 446 ms；微信在面板中实际右键打开原菜单，隐藏后仍能打开；菜单获得前台焦点，并在返回助手或切换至桌面时关闭；新界面实际运行；显示/隐藏状态及提示更新顺序修复。自包含 MSIX 打包流程已跑通，使用开发自签名证书。

自启动使用 Windows 正式启动任务，可随安装版本更新；启用与禁用已在打包身份下跑通，任务操作具有三秒上限并响应退出。手动显示/隐藏会解除该图标的活动隐藏规则，避免开关被立即反转。同值提示/显隐不重复写入；局部修改保留其他策略，失败不会触发后台高频重试。

所有选项菜单由原选框下方展开，选框文字保持可见，菜单与窗口采用相同的持久 Acrylic 和统一字体；设置名称与开关同排。主窗口和二级窗口使用 lan-device-monitor 同款窗口按钮，最小化灰色悬停、关闭红色渐变悬停，深浅色材质参数与 lan-device-monitor 一致，内容不叠额外灰色着色层。主窗口最小尺寸为 300×260 DIP，并移除最大化按钮。滚动条位于恒定边距内，需要滚动时始终可见，内容能完整显示时隐藏且不接收悬停；其有无不改变内容宽度，非悬停滑块宽度为 3 DIP，悬停为 5 DIP，中心位置固定，深浅主题采用柔和的低对比度颜色。常规态与悬停态采用源控件的 300 毫秒 Quadratic 非线性动画，浅色悬停更深，深色悬停更亮，不出现箭头或外框。系统图标自动读取，系统图标与高级设置直接完整展示。所有设置自动应用和持久化，连续输入合并写入，关闭窗口和托盘退出都会提交尚未完成的改动；保存失败保留修改供重试，连接恢复后补齐初始化。

## 构建

使用原工程 .NET 8 WPF、LLVM-MinGW 与 C++/WinRT。保留的 WinUI 前端使用 Windows App SDK 2.5.1。构建工具优先复用工作区 Common，机器快照、用户配置、图片、日志、符号与私钥均忽略。

```powershell
./build.ps1 -Target Agent
./build.ps1 -Target Bridge
./build.ps1 -Target CoreTests
./build.ps1 -Target SettingsTests
./build.ps1 -Target AgentVisibilityTests
./package.ps1
```
