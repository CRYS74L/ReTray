# dev.217 窗口按钮正常尺寸像素对齐

用户提供的实际截图显示符号仍有亚像素偏移。此前只检查 ContentPresenter 与 Ellipse 的布局中心及放大图，不足以验证最终栅格化结果。

新增继承标准 WPF Button 的 WindowTrafficLightButton，在同一 OnRender/DrawingContext 原点内绘制圆钮和符号，去除分别布局、取整的 Ellipse/Canvas/Path 层。保留原有点击命令、键盘操作、工具提示、悬停组绑定，以及 20 DIP 圆钮尺寸和已确认颜色/几何比例。

新增像素级回归：在 100%、125%、150%、200% 下分别渲染未悬停与悬停按钮；比较圆钮 alpha 重心与符号差分重心，同时断言悬停前后圆钮 alpha 轮廓一致。12 组测量的最大轴向偏差约 0.054 物理像素，均小于 0.06；焦点离开及悬停移出检查通过。

Release 构建零错误/警告；Apple controls 全部通过。已安装并打开 dev.217，663 个发布文件 SHA256 一致。材质、窗口圆角、导航和其他控件未改变。
