# dev.202 悬停过渡与内容比例修正

- 分段选项使用各自的文字画刷，在鼠标进入、离开及选择变化时执行 180ms EaseOut 颜色过渡。反向从当前显示颜色继续，旧动画完成事件不会覆盖新的目标。关闭系统动画时立即更新。
- 主题画刷只作为颜色来源，不直接动画共享资源；选项保持独立 Foreground，避免主题继承更新覆盖动画状态。
- 恢复历史时长原有 14 字号，与历史内容保持字级关系；容器改为 34 高度、左右 17 留白，按内容决定宽度。
- 设备右侧内容边距由 24 调整到 18，状态／速度区最小宽度由 68 调整到 60，收回过多空白且保留居中对齐。其他字号不变。

验证：Release 0 警告／0 错误；实际鼠标路由事件触发动画的回归检查，包含中间颜色、快速反向无跳色、进入和退出终点；选择与主题切换后的颜色一致性；设置快捷键、快速反向筛选回归；明暗主题和两种窗口大小的渲染检查。
