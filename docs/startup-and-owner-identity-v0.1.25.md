# v0.1.25 注册身份与登录自启动修复

MacTray 的现存注册与历史配置具有不同的非 GUID UID，原规则严格比较 UID，因而无法跨注册恢复隐藏偏好。针对已观察到的 MacTray / TPUtilWindow 组合，持久规则现在比较完整可执行文件路径和窗口类，实时操作仍使用原生 PID、创建时间、HWND 和 UID。其他应用的 UID / GUID 匹配方式保持原有语义。

旧 MacTray 规则自动迁移，重复注册规则保留最后保存的偏好，列表位置优先保留最后保存注册对应的位置。规则格式增加可选 matchUid 字段，旧文件默认继续严格匹配 UID；忽略 UID 的规则必须指定窗口类且不能同时使用 GUID。windowClassIsIdentity 区分稳定注册身份与用户明确设置的窗口筛选条件，身份窗口类不提高筛选优先级；旧明确窗口类规则仍优先于宽泛规则，不因数组顺序而反转偏好。列表位置按实际展示身份独立迁移，明确筛选或提示条件不会使列表位置失效。旧配置仍能读取，原有非 MacTray 规则、图片、提示和系统设置保留。

NVIDIA nvcontainer 的进程访问权限阻止普通 OpenProcess 查询，原目录得到空路径，生成的规则被配置校验拒绝。新身份读取保留普通查询，并在失败时只读查询系统进程信息，取得创建时间和映像路径，将设备路径转换成相同的 DOS 完整路径。原生完整快照和实时注册事件共享该查询；没有开放空路径规则，也没有提升ReTray权限。

本机 QQ 使用未设延迟的 LogonTrigger 计划任务。ReTray改用当前用户专属的同类任务，InteractiveToken、普通权限、IgnoreNew，无电池条件和运行时限。任务名包含当前用户 SID，更新或禁用前同时验证产品 Source 标记和所属用户；用户名先转换为 SID，以适配 Windows 的返回形式。同名未知任务返回冲突，绝不覆盖。

计划任务只寻址一个确定任务，不删除任务文件夹、不枚举后批量修改、不清空 Run 或 StartupApproved。未打包旧 Run 项仅在名称和完整命令都与当前ReTray一致时清理。打包版保留旧 startupTask 声明作为升级后的首次运行兜底：新任务创建成功后，在原 App 激活身份下禁用本包的旧入口。后台身份不调用不属于它的旧任务 API；单实例机制防止兜底入口重复启动后台。这也保留了更新后未先手动打开就重启的用户的原自启动能力。旧扩展的无参数自动启动入口另行检查已保存的 startup 偏好，关闭时直接退出，不注册托盘或连接桥接；界面及新激活器的显式 --background 启动仍能正常打开后台。因此即便旧扩展暂时不能禁用，也不能绕过用户的关闭偏好。

打包版通过固定保存在本包 LocalState/Startup 的小型 v1 启动器激活同一包的隐藏 Background 应用，后台继续读取相同安装身份的个人配置。此启动器不读取个人规则，任务路径不包含安装版本目录，登录时不打开主窗口。每次正常启动会刷新已启用任务的定义；已禁用用户不会被自动启用。自启动设置先校验、应用再持久化，失败保留原配置；保存失败时尝试恢复原启用状态。

扩展审查还修复了两类事务隐患。不可解析的图标身份在构建规则前被拒绝，目录开关暂时禁用，身份恢复时重新通知实际绑定控件；持久化在局部候选上归一化并捕获错误，成功写盘后才更新内存和 revision，失败不污染其他图标的配置。未打包旧 Run 项先完成权限及内容检查，再改ReTray自己的任务；删除旧项失败会恢复原任务偏好，恢复失败也明确报告。revision 与语言/激活标识字段的类型和界限经过校验，避免不合法配置传入界面。

验证覆盖核心规则 33 项、图标与目录 38 项、系统策略 16 项、桥接注册 4 项、WPF 绑定与开关 4 项，配置迁移/排序、系统身份查询与真实任务启用/禁用/更新/同名冲突保护。身份污染、注册表权限失败、删除失败和迁移优先级的回归均先复现再修复。真实 NVIDIA 原生事务和界面开关均完成隐藏/显示并保存；MacTray 的 UID、窗口和进程身份变化回归保持隐藏，未改变其他图标策略。真实计划任务激活验证读取同一配置且不打开前端；关闭自动启动后，无参数自动入口退出，手动打开仍可运行。

本机验收对 95 项 Run/RunOnce/StartupApproved 注册表记录、225 个原有计划任务的完整定义和启动文件夹文件进行前后核对。初次检查仅新增ReTray自己的任务，原项目均一致。最终追加检查中，95 项注册表记录和启动文件仍一致，225 个原有任务均保留，其中 224 个定义完全一致；Windows OneSettings/RefreshCache 的起始时间和重复间隔发生刷新，其他字段一致。该任务自身成功运行于 12:02:24，其文件在约两秒后更新，COM 处理器对应 Microsoft Windows 签名的 wosc.dll；当前执行身份非管理员、非 SYSTEM，而该任务只授予这些身份写权限。符合系统独立刷新的证据，但任务事件日志未启用，不能提供事件级写入者归因。本轮未调整或恢复该系统任务。QQ、MacType 和其他软件自启动项目未变化。

证据与个人配置备份存放在被 Git 忽略的 artifacts 目录。此核对是当前机器快照，不代表其他机器的项目数量。

实际电脑重启后的启动时间和 MacTray 恢复仍需下次自然登录观察。本轮不重启电脑或 Explorer；任务定义、手动触发和跨注册回归不替代真实重启验收。

复测入口：build.ps1 的 CoreTests、SettingsTests、AgentVisibilityTests、AgentSystemTests、BridgeRegistrationTests 和 StartupTests。StartupTests 仅创建并删除本轮按 PID 命名的临时测试任务，不启动其他软件。
