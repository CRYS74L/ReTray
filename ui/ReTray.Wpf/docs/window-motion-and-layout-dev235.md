# dev.235：窗口、过渡和布局复查

## 修正内容

- 设备列表滚动条末端扣除最后一个胶囊的 5 DIP 尾部留白，轨道不随列表平移。
- 视口渐隐范围由 12 扩为 36 DIP；强度随离边缘的滚动距离连续变化，并以 180ms 缓动追随新值，不再从全无直接跳到全有。
- 窄屏列表与详情往返接入 150ms 退出、450ms 进入的两段式动画，进入包含轻微位移和缩放。返回控件只保留箭头，仍有“返回设备列表”的辅助名称。窗口尺寸变化会清理未完成的动画状态。
- 侧栏保存的展开宽度与因窗口变窄而临时受限的宽度分开；窗口重新变宽后恢复保存值，不停在中间尺寸的窄栏宽度。
- 路由器标题栏按标题和操作区的实际内容宽度决定是否换行，不再使用等宽列的固定阈值。空间足够时保持一行；窄屏时状态与刷新成组左对齐。连接状态胶囊按文字自然宽度加固定内边距布局。
- 路由器重启区域恢复 dev.233 的图标、标题、说明、右侧按钮及二次确认结构；窄屏说明允许换行。测试没有触发真实重启。
- 原生标题栏高度设为 44 DIP，最大化拖动交给 Windows 的标题栏处理。保留红绿灯按钮为客户区命中，靠近区域避开 6 DIP 缩放边框；按钮屏幕位置和识别区左/下等距保持不变。
- 最大化时把玻璃材质的可见区域及页面内容限制在所在显示器工作区。Windows 自带的隐形缩放边框可仍位于工作区外，应用不再把它渲染成可见材质。恢复普通窗口时移除该裁剪；DPI 和系统工作区变化时重新计算。
- 降低蓝色图标圆底的对比度，提高灰色圆底的对比度，分别适配浅色、深色主题。
- 刷新间隔显示 `1 秒` 等细空格形式；应用提供的中英混排、数值与单位、时长分隔统一采用 U+2009。设备名称只调整显示层中英交界处的空格，存储值不变。网页的相关显示格式同步。
- 摄像头改为半圆机身、内部圆形镜头；插座改为上方接地孔与下方两个斜孔，保留圆角外框。插孔外观参考 [GB 1002—2024](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=F8C9E208891B7BB5AF1B3E64933693C2) 图 4；图标为界面示意，不承载工程尺寸。
- 侧栏按钮图形再缩小至 20 DIP。收起状态的路由器、设置按钮改为与侧栏按钮一致的轻量图标样式，仍为独立可点击控件。
- 按实际字形墨迹中心修正密码圆点的垂直位置，已保存密码遮罩与正在输入的密码均应用。未读取或输出真实密码。
