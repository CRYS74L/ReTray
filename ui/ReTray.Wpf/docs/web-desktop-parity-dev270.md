# 局域网页面与桌面界面对齐（dev.270）

设计基准是当前桌面软件（dev.269）及用户提供的截图，不生成或采用新的界面方案。

## 范围与对照

- 设备栏：软件原图标、名称、在线/离线滑块、完整设备图标、状态变化时长、选择/悬停、底部连接状态与路由器/设置圆形按钮、收起侧栏。
- 设备详情：图标/名称、连接信息、流量统计标题及 1/5/10 分钟滑块、曲线与四项指标、统计区间胶囊、上下线历史与同排时长、按十五条展开/收起、设备设置与离线设备管理。
- 路由器：网络连接、IPv4/IPv6、Mesh 节点与连接关系、刷新及路由器控制的显示。
- 设置：通用、路由器连接、通知（含新设备）、免打扰时段、局域网访问、版本。
- 浅/深色、900 DIP 对应断点、窄屏单页/返回、720 DIP 内容上限、固定控件尺寸、默认字号、日期空隙、布局边距、圆角和描边。
- 动效：筛选滑块与内容、页面退出/进入、紧凑页切换、侧栏收起、按钮悬停/按压、历史展开及反向中断、统计区间退出跟随与淡出；刷新不反复播放入场。

复用桌面 Microsoft YaHei UI、Segoe Fluent Icons 与设备矢量路径、软件原 PNG。网页原有手机导航、搜索、独立历史弹层、合计用量/说明等桌面没有的结构移除。

## 权限与平台边界

维持既有 GET/HEAD-only 局域网服务与 host/origin/LocalSubnet 限制。桌面设置和设备提醒状态同步显示；网页主题可单独调整显示，电脑启动、Windows 通知、设备移除、路由器重启与凭据修改不通过网页执行。管理员密码仅提供是否已保存的布尔值，不发送密码。

浏览器无法读取窗口背后的桌面内容，原生 DWM Acrylic 的实时模糊不是 CSS 的能力。网页使用相同的前景颜色、半透明图层和边框，配合浏览器内材质背景；不声称原生材质与不同桌面壁纸逐像素一致。浏览器自带窗口按钮不作为网页控件复制。

用户追加要求：网页不保留顶部 Windows 标题栏的 32px 空白；竖屏直接显示内容，移除外层窗口面板的圆角和描边，内部连接/流量/历史等卡片仍保留原样式。

## 实施验证

以相同合成设备、路由器数据制作桌面参照与网页渲染；宽屏/窄屏、浅/深色分别比较。保留真实服务及数据只读测试，检查导航、在线/离线筛选、刷新、统计区间、历史分页/展开、主题、侧栏、滚动、无空白/越界/控制台错误和减少动态效果。测试不操作真实路由器或 Windows 设置。

测试入口：`node --test tests/web-chart.test.mjs tests/web-desktop-parity.test.mjs`、`--web-access-regression`、`--detail-responsive-layout-regression`、`--desktop-web-reference-capture`。浏览器交互检查覆盖 380、440、480、500、600、899、900、1180、1218 CSS px，浅深色及 125% DPI。合成预览与原生捕获只服务验证，不发布为真实设备数据。

浏览器排版与 WPF 的文字抗锯齿方式不同；同源字体、字号、文字起点和控件布局的对齐不能保证跨浏览器、跨操作系统的每个像素一致。原生抓图使用中性背景而非桌面壁纸，材质颜色不作为逐像素通过标准。移动端去外框、网页去标题栏留空以及只读能力是明确的平台差异。
